Combine CDAScorer annotation datasets

Date: 19/06/2025

GOHREP

Goal:

Combine the CDAScorer annotation datasets into one table.

Hypothesis:

N/A

Rationale:

Having three scorers allows some confidence in the ground truth labels to be passed to the model. With a median score: 1. If all three scorers give the same score, then that agreed score becomes ground truth 2. If two scorers give one score, and another scorer gives a different score, then the majority score becomes ground truth 3. If all scorers give different scores, the least extreme score becomes the ground truth

Experimental plan:

  1. Load in all the CDAScorer data tables
  2. Create a new data table to contain the combined dataset, with Scorer1, Score1, X1_1, X2_1, Y1_1, Y2_1 etc.
  3. To this table add all of the unique combinations of File, Row, Col, Pos that appear across the datasets.
  4. Load in the randomised_info.csv data, which contains information about who scored each image. Use this to fill in Scorer1, Scorer2, and Scorer3 columns.
  5. For each row, loop through those scorers, access their CDAScorer data tables for the current CDA, and add their score and coordinates to the corresponding columns of the output table.
  6. Generate an anonymisation key mapping scorer names to integer IDs.
  7. Anonymise scorer columns and save the combined tables. The key (anonymisation_key.csv) is the only record of real names and is not uploaded to Zenodo.

# 3
# Both sets use the same combined randomised_info.csv (Set column distinguishes them).
# combine_CDA_dataframes filters to the relevant rows via a left join on basename.
scorer_info = repo_root / "analyses/01_generate_raw_data/01_allocation_info/randomised_info.csv"

combined_CDA_data1 = dataset_preparation.combine_CDA_dataframes(cda_dataframes1, scorer_info)
combined_CDA_data2 = dataset_preparation.combine_CDA_dataframes(cda_dataframes2, scorer_info)
out_dir = repo_root / "analyses/01_generate_raw_data/02_combining_cdascorer_outputs"
# Generate anonymisation key from all unique scorer names across both sets and
# all three scorer columns. The key is the only place real names are recorded,
# kept in anonymisation_keys/ (repo root) rather than alongside the pipeline
# output - it is not uploaded to Zenodo.
combined_both = pd.concat([combined_CDA_data1, combined_CDA_data2], ignore_index=True)
all_scorer_names = pd.concat([
    combined_both['Scorer1'].dropna(),
    combined_both['Scorer2'].dropna(),
    combined_both['Scorer3'].dropna(),
]).unique()
key = human_performance.generate_scorer_key(
    pd.DataFrame({'Scorer1': all_scorer_names}),
    random_state=42,
    output_path=str(repo_root / "anonymisation_keys" / "anonymisation_key.csv"),
)
print(f"Anonymisation key: {len(key)} scorers")

combined_CDA_data1 = human_performance.anonymise_scorers(combined_CDA_data1, key)
combined_CDA_data2 = human_performance.anonymise_scorers(combined_CDA_data2, key)
combined_CDA_data1.to_csv(out_dir / "combined_cda_data_1.csv", index=False)
combined_CDA_data2.to_csv(out_dir / "combined_cda_data_2.csv", index=False)
print("Anonymised outputs saved.")
