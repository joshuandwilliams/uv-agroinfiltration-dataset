Experimental differences between raw images

Date: 08/06/2026

1. GOHREP

Goal:

Do pairwise scoring frequencies match our expectations given the image distribution strategy?

Are there differences in CDA counts per raw agro image between different experiments, and do those experiments differ in how consistently they were scored?

Hypothesis:

In part 1 of the CDA dataset, scorers will have collected fewer scores than expected. In part 2 of the dataset, they will match the expected number of scores collected.

There will be differences in CDA counts per raw agro image, and in scoring agreement, between different experiments.

Rationale:

Part 1 of the CDA dataset contains some dual-infiltration CDAs, which were ignored during scoring but not during raw agro image distribution. Part 2 does not.

Different experiments used different biological systems, different numbers of leaves per raw image, and different numbers of infiltrations per leaf.

The image distribution strategy itself is documented separately in 01_generate_raw_data/01_allocation_info/image_distribution_strategy.qmd.

2. Dual-infiltration images

Some images contained both yellow/green and orange CDAs (“dual-infiltration” images, see example below). The orange CDAs were ignored during scoring, but not during the raw agro image allocation estimates. The dual-infiltration images are all of the Project G and Project E experiments.

long_score_table <- function(data) {
  long <- data %>%
    select(Basename, Row, Col, Pos,
           Scorer1, Score1, Scorer2, Score2, Scorer3, Score3) %>%
    pivot_longer(
      cols          = c(Scorer1, Score1, Scorer2, Score2, Scorer3, Score3),
      names_to      = c(".value", "num"),
      names_pattern = "(Scorer|Score)(\\d+)"
    ) %>%
    select(-num) %>%
    filter(!is.na(Scorer), Score != "[]")
  long$Scorer <- factor(long$Scorer, levels = sort(as.numeric(unique(long$Scorer))))
  return(long)
}

pairwise_score_data <- function(score_data_long){
    data <- score_data_long %>%
    mutate(Score = as.numeric(Score)) %>%
    group_by(Basename, Row, Col, Pos) %>%
    mutate(id = row_number()) %>%
    ungroup()

    pairwise_comparisons <- data %>%
    full_join(data, by = c("Basename", "Row", "Col", "Pos"), relationship = "many-to-many") %>%
    filter(id.x < id.y) %>%
    select(Scorer.x = Scorer.x, Score.x = Score.x, Scorer.y = Scorer.y, Score.y = Score.y) %>%
    group_by(Scorer.x, Score.x, Scorer.y, Score.y) %>%
    summarise(Count = n(), .groups = 'drop')

    filtered_data <- pairwise_comparisons %>%
    filter(!is.na(Score.x) & !is.na(Score.y))

    filtered_copy <- filtered_data
    names(filtered_copy)[names(filtered_copy) %in% c("Scorer.x", "Scorer.y")] <- c("Scorer.y", "Scorer.x")

    filtered_data <- rbind(filtered_data, filtered_copy)

    agreement_data <- filtered_data %>%
    group_by(Scorer.x, Scorer.y) %>%
    summarise(Total = sum(Count),
                Agree = sum(Count * (Score.x == Score.y)),
                Percent_Agree = (Agree / Total) * 100,
                .groups = 'drop')

    agreement_data <- agreement_data[as.integer(agreement_data$Scorer.x) < as.integer(agreement_data$Scorer.y), ]

    all_combinations <- expand.grid(Scorer.x = unique(agreement_data$Scorer.x), Scorer.y = unique(agreement_data$Scorer.y))

    merged_df <- all_combinations %>%
    left_join(agreement_data, by = c("Scorer.x", "Scorer.y")) %>%
    mutate(Total = ifelse(is.na(Total), NA, Total),
            Agree = ifelse(is.na(Agree), NA, Agree),
            Percent_Agree = ifelse(is.na(Percent_Agree), NA, Percent_Agree)) %>%
    filter(as.integer(Scorer.x) < as.integer(Scorer.y))

    merged_df$Scorer.y <- factor(merged_df$Scorer.y, levels = sort(unique(merged_df$Scorer.y)))

    return(merged_df)
}

average_pairwise_agreement <- function(data) {
  valid_data <- data[!is.na(data$Total) & !is.na(data$Percent_Agree), ]
  sum(valid_data$Percent_Agree * valid_data$Total) / sum(valid_data$Total)

9. Sensitivity analysis: removing experiments

Each experiment is removed in turn (along with any two-scorer CDAs that then disagree), and the overall pairwise agreement is recomputed.

Code 
remove_experiment <- function(score_data_long, experiment, remove_2_disagree){
    subset_score_data <- subset(score_data_long, Folder != experiment)

    if (remove_2_disagree == TRUE) {
      groups_with_issues <- subset_score_data %>%
        group_by(Basename, Row, Col, Pos) %>%
        filter(n() == 2) %>%
        mutate(diff_scores = n_distinct(Score) > 1) %>%
        filter(diff_scores) %>%
        ungroup() %>%
        select(Basename, Row, Col, Pos)

      subset_score_data <- subset_score_data %>%
        anti_join(groups_with_issues, by = c("Basename", "Row", "Col", "Pos"))
    }
    return(subset_score_data)
}
