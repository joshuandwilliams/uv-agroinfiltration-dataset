Project differences between raw images

Date: 08/06/2026

GOHREP

Goal:

Do pairwise scoring frequencies match our expectations given the image distribution strategy?

Are there differences in CDA counts per raw agro image between different projects, and do those projects differ in how consistently they were scored?

Hypothesis:

In part 1 of the CDA dataset, scorers will have collected fewer scores than expected. In part 2 of the dataset, they will match the expected number of scores collected.

There will be differences in CDA counts per raw agro image, and in scoring agreement, between different projects.

Rationale:

Part 1 of the CDA dataset contains some dual-infiltration CDAs, which were ignored during scoring but not during raw agro image distribution. Part 2 does not.

Different projects used different biological systems, different numbers of leaves per raw image, and different numbers of infiltrations per leaf.

The image distribution strategy itself is documented separately in 01_generate_raw_data/01_allocation_info/image_distribution_strategy.qmd.

1. Dual-infiltration images

Some images contained both yellow/green and orange CDAs (“dual-infiltration” images, see example below). The orange CDAs were ignored during scoring, but not during the raw agro image allocation estimates. The dual-infiltration images are all from Project C and Project H (per project_anonymisation_key.csv’s Dual_Infiltration column).

8. Sensitivity analysis: removing projects

Each project is removed in turn (along with any two-scorer CDAs that then disagree), and the overall pairwise agreement is recomputed.

Code 
# 8.1
remove_project <- function(score_data_long, project, remove_2_disagree) {
  subset_score_data <- subset(score_data_long, Folder != project)

  if (remove_2_disagree == TRUE) {
    groups_with_issues <- subset_score_data %>%
      group_by(Basename, Row, Col, Pos) %>%
      filter(n() == 2) %>%
      mutate(diff_scores = n_distinct(Score) > 1) %>%
      filter(diff_scores) %>%
      ungroup() %>%
      select(Basename, Row, Col, Pos)

    subset_score_data <- subset_score_data %>%
      anti_join(groups_with_issues, by = c("Basename", "Row", "Col", "Pos"))
  }
  subset_score_data
}

# 9
cda_folder <- median_long %>%
  distinct(Basename, Row, Col, Pos, Median_Score) %>%
  left_join(folder_map, by = "Basename")

class_pct <- cda_folder %>%
  count(Folder, Median_Score, name = "Count") %>%
  group_by(Folder) %>%
  mutate(Proportion = Count / sum(Count)) %>%
  ungroup()

folder_totals <- cda_folder %>%
  count(Folder, name = "Total")

folder_labels <- setNames(
  paste0(folder_totals$Folder, "\n(n=", folder_totals$Total, ")"),
  folder_totals$Folder
)

p <- ggplot(class_pct, aes(x = Folder, y = factor(Median_Score), fill = Proportion)) +
  geom_tile(color = "black") +
  geom_text(aes(label = sprintf("%.1f%%", Proportion * 100)), color = "black", size = 4.5) +
  scale_fill_gradient(name = "Proportion", low = "white", high = "firebrick") +
  scale_x_discrete(labels = folder_labels) +
  coord_equal() +
  labs(x = "Project", y = "Score Class") +
  theme_minimal() +
  theme(
    axis.text.x = element_text(angle = 45, hjust = 1),
    axis.text = element_text(size = 13),
    axis.title = element_text(size = 15),
    legend.title = element_text(size = 13),
