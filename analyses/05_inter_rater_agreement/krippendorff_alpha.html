Inter-Rater Reliability: Krippendorff’s Alpha and Residual Correlation

Date: 2026-06-03

GOHREP

Goal:

Quantify the overall inter-rater reliability of the human scorer panel using Krippendorff’s alpha, and characterise the structure of scorer disagreement via Pearson correlation of score residuals.

Hypothesis:

  1. Krippendorff’s alpha on raw scores will be high (>0.8), reflecting that scorers broadly agree on severity ordering even when they differ by ±1.
  2. Alpha on residuals (score − median) will be substantially lower, indicating that scorers do not share structured error patterns.
  3. Residual correlations between scorer pairs will be positive but moderate — scorers make similar errors but not identical ones.

Rationale:

Pairwise % agreement (see pairwise_agreement.qmd) captures agreement on exact score matches but does not give a single overall reliability estimate. Krippendorff’s alpha is the standard metric for ordinal inter-rater reliability and handles missing data (not all scorers rated all CDAs). Residual correlation is ported from the model ensemble analysis in AutoCDAScorer_Models/analyses/10_model_scoring_patterns/model_error_independence.Rmd where it was used to assess whether model errors were structured or independent.

Experimental plan:

Compute Krippendorff’s alpha on raw scores (ordinal metric) and on score residuals (interval metric), bootstrap each to obtain 95% CIs, then compute and visualise pairwise Pearson correlation of residuals.

2. Krippendorff’s Alpha — Raw Scores

Krippendorff’s alpha is computed on the full scorer × CDA matrix directly (no median involved). Two distance metrics are compared as a robustness check on the assumed measurement level: ordinal (treats 0–6 as ordered categories) and interval (treats 0–6 as equally spaced). If the two estimates agree, the reliability conclusion doesn’t hinge on which scale assumption is correct. Missing values are handled automatically: expected agreement is estimated from all rated pairs.

Code 
# 2.1.1
alpha_raw <- kripp.alpha(scorer_matrix, method = "ordinal")
cat("Krippendorff's alpha (ordinal, raw scores):", round(alpha_raw$value, 4), "\n")

3. Krippendorff’s Alpha — Score Residuals

Residuals are computed as (individual score − CDA median score), then Krippendorff’s alpha is recomputed on the residual matrix. A high residual alpha would indicate that scorers share structured error patterns (they make the same mistakes); a low residual alpha indicates independent errors.

Code 
# 3
# Align median scores to scorer_matrix column order by CDA_ID
cda_medians <- raw_data %>%
  mutate(CDA_ID = paste(Basename, Row, Col, Pos, sep = "_")) %>%
  select(CDA_ID, Median_Score) %>%
  distinct() %>%
  {
    setNames(.$Median_Score, .$CDA_ID)
  }

median_vec <- as.numeric(cda_medians[colnames(scorer_matrix)])

residual_matrix <- scorer_matrix - matrix(
  rep(median_vec, each = nrow(scorer_matrix)),
  nrow = nrow(scorer_matrix),
  dimnames = dimnames(scorer_matrix)
)

alpha_resid <- kripp.alpha(residual_matrix, method = "interval")
cat("Krippendorff's alpha (interval, residuals):", round(alpha_resid$value, 4), "\n")
Krippendorff's alpha (interval, residuals): -0.1287

4. Pearson Correlation of Score Residuals

For each pair of scorers who shared at least one CDA, compute the Pearson correlation of their residuals across those shared CDAs. A high correlation means their errors tend to go in the same direction; a low or near-zero correlation means their errors are largely independent (good for ensemble/median robustness).

Code 
# 4.1
# rownames(scorer_matrix) are in pivot order, not sorted, so map each scorer ID
# back to its matrix row and build pairs ordered by ID (Scorer.x < Scorer.y).
# This keeps every tile in the upper-left triangle like the other heatmaps.
scorer_ids <- as.integer(rownames(scorer_matrix))
row_of <- setNames(seq_along(scorer_ids), scorer_ids)

pairs <- expand.grid(Scorer.x = scorer_ids, Scorer.y = scorer_ids) %>%
  filter(Scorer.x < Scorer.y)

cor_results <- pairs %>%
  rowwise() %>%
  mutate(
    i = row_of[[as.character(Scorer.x)]],
    j = row_of[[as.character(Scorer.y)]],
    shared = sum(!is.na(residual_matrix[i, ]) & !is.na(residual_matrix[j, ])),
    correlation = if (shared >= 10) {
      cor(residual_matrix[i, ], residual_matrix[j, ],
        use = "pairwise.complete.obs"
      )
    } else {
      NA_real_
    }
  ) %>%
  ungroup() %>%
  select(Scorer.x, Scorer.y, shared, correlation)

print(
  cor_results %>%
    select(Scorer.x, Scorer.y, shared, correlation) %>%
    arrange(correlation)
)
