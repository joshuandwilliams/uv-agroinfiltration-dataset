Pairwise Agreement and Per-Image Analysis

Date: 15/5/2024 – 10/6/2024

GOHREP

Goal:

Investigate changes to average pairwise agreement when each rater is removed. Investigate differences in agreement across raw agroinfiltration images.

Hypothesis:

Excluding scores from raters with low pairwise agreement will increase the overall average pairwise agreement. Some images will be scored more consistently than others due to differences in clarity or familiarity.

Rationale:

Differences in lighting or leaf clarity could cause some images to be scored less consistently. Identifying which raters most reduce overall agreement informs future data collection decisions.

2.1 Off-by-one disagreement rate

How often do two raters differ by exactly one severity point? Pooled across all unordered rater pairs per CDA, the off-by-one rate is the near-miss rate (|diff| ≤ 1) minus the exact rate (diff = 0).

Code 
# 2.1
pairwise_diffs <- function(score_data_long) {
  d <- score_data_long %>%
    mutate(Score = as.numeric(Score)) %>%
    group_by(Basename, Row, Col, Pos) %>%
    mutate(id = row_number()) %>%
    ungroup()

  d %>%
    full_join(d,
      by = c("Basename", "Row", "Col", "Pos"),
      relationship = "many-to-many"
    ) %>%
    filter(id.x < id.y) %>%
    transmute(
      Median_Score = as.numeric(Median_Score.x),
      absdiff = abs(Score.x - Score.y)
    )
}

What this shows:

  • Across all CDAs, two raters differ by exactly one severity point ~29% of the time. This is dominated by median-0 CDAs, on which raters almost always agree exactly.
  • Restricting to non-zero-median CDAs, the off-by-one rate rises to ~45%: on the CDAs that actually carry disease signal, an off-by-one disagreement is the single most common outcome between any two raters.

remove_scorer <- function(score_data_long, scorer, remove_2_disagree) {
  subset_score_data <- subset(score_data_long, Scorer != scorer)

  if (remove_2_disagree) {
    groups_with_issues <- subset_score_data %>%
      group_by(Basename, Row, Col, Pos) %>%
      filter(n() == 2, n_distinct(Score) > 1) %>%
      ungroup() %>%
      select(Basename, Row, Col, Pos)

    subset_score_data <- subset_score_data %>%
      anti_join(groups_with_issues, by = c("Basename", "Row", "Col", "Pos"))
  }
  subset_score_data
}

unique_scorers <- c("Original", as.character(sort(as.numeric(unique(score_data_long$Scorer)))))

results <- lapply(unique_scorers, function(scorer) {
  subset_T <- remove_scorer(score_data_long, scorer, TRUE)

Why does pairwise agreement increase for most rater removals?

When a rater is removed, CDAs that now have only 2 remaining scores are also removed — but only if those 2 scores disagree. Since disagreement occurs ~36% of the time, each rater removal also removes a further 36% of the CDAs that rater uniquely shared, biasing the remaining pool toward agreement.

5. Verification: Random Sampling Gives the Same Average Agreement

# 5
random_sample_pair_agree <- function(data, sample_num) {
  set.seed(42)
  CDA_set <- distinct(data, Basename, Row, Col, Pos)
  CDA_set <- CDA_set[sample(nrow(CDA_set)), ]
  sample_num <- min(sample_num, nrow(CDA_set))

  agreement_vector <- vapply(seq_len(sample_num), function(i) {
    sub <- data %>%
      filter(
        Basename == CDA_set$Basename[i], Row == CDA_set$Row[i],
        Col == CDA_set$Col[i], Pos == CDA_set$Pos[i]
      )
    if (nrow(sub) == 3) sub <- sub[-sample(1:3, 1), ]
    as.numeric(nrow(sub) == 2 && sub$Score[1] == sub$Score[2])
  }, numeric(1))

  mean(agreement_vector)
}

gen_pairwise_counts <- function(score_data_long) {
  data <- score_data_long %>%
    mutate(Score = as.numeric(Score)) %>%
    group_by(Basename, Row, Col, Pos) %>%
    mutate(id = row_number()) %>%
    ungroup()

  pairwise <- data %>%
    full_join(data, by = c("Basename", "Row", "Col", "Pos"), relationship = "many-to-many") %>%
    filter(id.x < id.y) %>%
    select(Scorer.x, Score.x, Scorer.y, Score.y) %>%
    group_by(Scorer.x, Score.x, Scorer.y, Score.y) %>%
    summarise(Count = n(), .groups = "drop") %>%
    filter(!is.na(Score.x) & !is.na(Score.y))

  sym_copy <- pairwise
  names(sym_copy)[names(sym_copy) %in% c("Scorer.x", "Scorer.y")] <- c("Scorer.y", "Scorer.x")
  names(sym_copy)[names(sym_copy) %in% c("Score.x", "Score.y")] <- c("Score.y", "Score.x")
  rbind(pairwise, sym_copy) %>%
    mutate(Count_Binned = cut(Count,
      breaks = c(0, 1, 10, 100, 250, Inf),
      labels = c("1", "2-10", "11-100", "101-250", "251-1000"),
      include.lowest = TRUE
    ))
}

make_patterns_plot <- function(sdl) {
  counts <- gen_pairwise_counts(sdl)
  levels_xy <- as.character(1:10)
  counts <- counts %>%
    mutate(
      Scorer.x = factor(Scorer.x, levels = levels_xy),
      Scorer.y = factor(Scorer.y, levels = levels_xy)
    )
  complete_counts <- complete(counts,
    Scorer.x = factor(levels_xy, levels = levels_xy),
    Scorer.y = factor(levels_xy, levels = levels_xy),
    fill = list(Count = 0)
  ) %>%
    mutate(Scorer.y = fct_rev(Scorer.y))
  real_counts <- complete_counts %>% filter(Count > 0)

  ggplot(complete_counts, aes(x = Score.x, y = Score.y)) +
    geom_tile(aes(fill = Count_Binned), color = "black", linewidth = 0.5) +
    geom_abline(intercept = 0, slope = 1, linetype = "dashed", color = "grey40") +
    scale_fill_manual(
      values = c(
        "1" = "#eff3ff",
        "2-10" = "#9ecae1",
        "11-100" = "#3182bd",
        "101-250" = "#fdae61",
        "251-1000" = "#d73027"
      ),
      name = "Frequency", na.value = "white", drop = FALSE
    ) +
    facet_grid(Scorer.y ~ Scorer.x, switch = "both") +
    theme_bw() +
    labs(x = "Rater X", y = "Rater Y") +
    theme(
      panel.spacing = unit(0.25, "lines"),
      strip.placement = "outside",
      panel.grid = element_blank(),
      strip.text = element_text(size = 11),
      axis.text = element_text(size = 10),
      axis.title = element_text(size = 13),
      legend.title = element_text(size = 13),
      legend.text = element_text(size = 11)
    )
}

10. Temporal test 2 — original scoring (image-ordered)

The original scoring was done in image order, with thousands of scores per rater — far more power, but consecutive CDAs usually share an image. Each score is compared to the leave-one-out consensus (the median, i.e. mean, of the other two raters on that CDA), giving a residual score − consensus. Scores are matched to the canonical panel by image and CDA position; the leave-one-out reference removes the self-inclusion that would otherwise force a score to match its own median.

# 10
# Wald-Wolfowitz runs test on the sign of a series (p-value only; zeros dropped).
runs_p <- function(x) {
  s <- sign(x[x != 0])
  n <- length(s)
  n1 <- sum(s > 0)
  n2 <- sum(s < 0)
  if (n1 == 0 || n2 == 0 || n < 3) {
    return(NA_real_)
  }
  runs <- 1 + sum(s[-1] != s[-n])
  mu <- 1 + 2 * n1 * n2 / n
  v <- 2 * n1 * n2 * (2 * n1 * n2 - n) / (n^2 * (n - 1))
  2 * pnorm(-abs((runs - mu) / sqrt(v)))
}

11. Image-level structure of disagreement (confound-free)

The temporal tests show disagreement is organised at the image level, but the raw-score autocorrelation conflates several things (the experimental layout, the abundance of agreed 0s, per-image bias). A cleaner test, free of temporal order and of the self-vs-median issue, looks at the difference between two raters on the same CDA: the true severity cancels, leaving only their relative disagreement. If that difference is consistent within an image but shifts between images, disagreement has an image-level component. This is the intraclass correlation (ICC) of the pairwise difference with image as the grouping factor: the fraction of disagreement variance attributable to which image a CDA is on.

# All within-CDA rater pairs, oriented lower-ID minus higher-ID, with image label.
mk_pair <- function(d, a, b) {
  d %>%
    transmute(Basename, Median_Score,
      sa = .data[[paste0("Scorer", a)]], sb = .data[[paste0("Scorer", b)]],
      ya = .data[[paste0("Score", a)]], yb = .data[[paste0("Score", b)]]
    ) %>%

    mutate(
      pair = paste(pmin(sa, sb), pmax(sa, sb), sep = "-"),
      diff = if_else(sa < sb, ya - yb, yb - ya)
    )
}

# Random-effects (one-way ANOVA) ICC of the difference by image, for one rater-pair.
icc_by_pair <- function(df) {
  g <- df %>%
    group_by(Basename) %>%
    summarise(ni = n(), mi = mean(diff), .groups = "drop") %>%
    filter(ni >= 2)
  df <- df %>% semi_join(g, by = "Basename")
  k <- nrow(g)
  N <- nrow(df)
  if (k < 3 || N < 10) {
    return(tibble(k = k, N = N, icc = NA_real_, btw_sd = NA, wth_sd = NA))
  }
  grand <- mean(df$diff)
  ss_b <- sum(g$ni * (g$mi - grand)^2)
  g_mi <- g %>% select(Basename, mi)
  ss_w <- df %>%
    left_join(g_mi, by = "Basename") %>%
    summarise(s = sum((diff - mi)^2)) %>%
    pull(s)
  ms_b <- ss_b / (k - 1)
  ms_w <- ss_w / (N - k)
  n0 <- (N - sum(g$ni^2) / N) / (k - 1)
  var_b <- max(0, (ms_b - ms_w) / n0)
  var_w <- ms_w
  tibble(k = k, N = N, icc = var_b / (var_b + var_w), btw_sd = sqrt(var_b), wth_sd = sqrt(var_w))
}

run_icc <- function(dat, label) {
  res <- dat %>%
    group_by(pair) %>%
    group_modify(~ icc_by_pair(.x)) %>%
    ungroup() %>%
    filter(!is.na(icc)) %>%
    mutate(subset = label)
  cat(sprintf(
    "[%s] %d pairs | median ICC = %.3f | within-image SD = %.2f | between-image SD = %.2f\n",
    label, nrow(res), median(res$icc), median(res$wth_sd), median(res$btw_sd)
  ))
  res
}

12.13 Confounds and interpretation (image-level structure)

Same image = same experiment. Original scoring is not a random sequence. CDAs on one image are spots on one leaf from one infiltration, so they share construct, leaf age, lighting and background. Two effects follow: (i) the underlying severities are correlated, and (ii) a rater’s reading of that leaf (exposure, contrast, what counts as “necrotic” under that lighting) is correlated. The §10 within-image autocorrelation and the §11 ICC both capture this image-level structure; neither is evidence of temporal anchoring, which the randomised rescore (see 06_intra_rater_reliability) and the across-image boundary (§10.1) both rule out.

The abundance of 0s and non-random layout. Infiltration layouts group controls together, so a rater genuinely does see runs of 0s — but those are near-universally agreed, so they contribute agreement, not disagreement structure. This is why the analyses use residuals / pairwise differences rather than raw scores (which would be trivially autocorrelated by the design), and why the §11 ICC is computed both with and without 0s. The result is reassuring: excluding 0s increases the image-level ICC, so the structure lives in the contested mid-range CDAs, not in the clustered controls.

Is class balancing necessary? For the temporal tests, no — and it would be harmful: down-sampling or re-weighting score classes destroys the true adjacency of the sequence, so a “lag-1” on a balanced series no longer means consecutive-in-time. The appropriate controls there are analysing residuals (not raw scores) and the within/across-image split, both of which are done. For the image-level ICC, balance is handled implicitly: the difference between two raters already removes the severity (class) signal, and reporting the non-zero subset alongside the full set shows the conclusion is not driven by the dominant 0 class.

Overall. Over-/under-scoring does not have temporal momentum across contexts — a rater’s last score does not pull their next one once the image changes. What is real is a modest image-level structure to disagreement: two raters’ relative calibration drifts somewhat from image to image (plausibly per-leaf lighting/background and per-session adaptation) while staying more consistent within an image. Most disagreement, however, remains CDA-specific — the irreducible ambiguity of scoring an individual cell-death area.
