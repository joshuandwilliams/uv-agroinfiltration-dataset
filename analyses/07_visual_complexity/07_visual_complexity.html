PCA of CDA image dataset

Date: 18/3/24 and 25/3/24

GOHREP

Goal:

  1. See how images cluster together following PCA Dimensionality Reduction
  2. Identify images that cluster most distantly from others of their score

Hypothesis:

  1. Images of the same score will cluster together
  2. Images of adjacent scores will cluster closer than those of more distant scores
  3. Some images will cluster far from other images of the same score, which may indicate mislabelling

Rationale:

Images of the same score are likely to be more similar than images of different scores, and images of adjacent scores are likely to be more similar than those of distant scores.

Due to variation in human scoring, even with the median of three scores taken, there may be human errors or biases which result in image misclassifications. However, these images that appear to be misclassified may instead just be uncommon.

Background

How does PCA work?

PCA is a dimensionality reduction technique, aiming to capture the most important information in the data and minimizing redundancy and noise.

  1. Build a covariance matrix which captures the relationships between pairs of variables (in our case variables are pixel values). A high covariance suggests a strong relationship.
  2. Calculate eigenvectors, which are directions in the original multidimensional feature space, representing a PC. Calculate eigenvalues, which are the magnitude of variance captured by the corresponding eigenvector.
  3. Rank PCs by their eigenvalues.
  4. Transform the input data into a new coordinate system defined by the principal components.

For each image, the total number of variables is: 64 x 64 x 3 = 12,288 Given this large number of variables, there is likely to be more variability in the data and capturing this with a small number of principal components is more challenging.

1.2 Load images and labels

Undersampling:

  • PCA does not use any class labels to reduce the dimensionality. However, it acts on the dataset as a whole to maximise the variance explained by any eigenvectors.
  • If the classes are unbalanced, the PCA may be biased towards explaining variance in the larger classes (such as 0).
  • We want the PCA to capture the underlying variance of all classes more equally, which gives a rationale for undersampling.
  • The same is true in the k-nearest neighbour clustering. If one group is much larger (e.g. 0s), in the PCA regions where that group overlaps with others (e.g. 1s or 2s), the closest neighbouring points to any given point in that region will likely be from the larger group, biasing the predictions towards that larger group.

def downsample_oversized_classes(train_images, train_labels, train_filepaths, per_class_train_size):
    # Undersample the classes larger than per_class_train_size
    undersampled_images, undersampled_labels, undersampled_filepaths = [], [], []
    for label in np.unique(train_labels):
        samples_indices = np.where(train_labels == label)[0]
        if len(samples_indices) > per_class_train_size:
            samples_indices = resample(samples_indices, replace=False, n_samples=per_class_train_size, random_state=42)
        undersampled_images.extend(train_images[samples_indices])
        undersampled_labels.extend(train_labels[samples_indices])
        undersampled_filepaths.extend(train_filepaths[samples_indices])

    # Shuffle the data
    undersampled_images = np.array(undersampled_images)
    undersampled_labels = np.array(undersampled_labels)
    undersampled_filepaths = np.array(undersampled_filepaths)
    shuffle_indices = np.random.permutation(len(undersampled_labels))
    undersampled_images = undersampled_images[shuffle_indices]
    undersampled_labels = undersampled_labels[shuffle_indices]
    undersampled_filepaths = undersampled_filepaths[shuffle_indices]

    return undersampled_images, undersampled_labels, undersampled_filepaths

def implement_pca(images):
    images_array = np.array(images)
    images_array = images_array.reshape(len(images_array), -1)

    pca = PCA(n_components=10)
    pca.fit(images_array)
    images_pca = pca.transform(images_array)

    return pca, images_pca

# 5.1
from sklearn.metrics import silhouette_score, adjusted_rand_score, normalized_mutual_info_score, fowlkes_mallows_score
from sklearn.neighbors import NearestNeighbors


def nearest_neighbour_clustering(true_labels, images_pca, name):
    best_k = None
    best_silhouette_score = -1  # Initialize with a low value
    best_ari = -1  # Initialize with a low value

    for k in range(1, 11):
        # Initialize the k-nearest neighbors model
        nbrs = NearestNeighbors(n_neighbors=k, metric='euclidean')

        # Fit the model to your PCA-transformed images
        nbrs.fit(images_pca)

        # kneighbors() with no argument excludes each point from its own neighbourhood,
        # giving a leave-one-out evaluation equivalent to a held-out test for every image.
        distances, indices = nbrs.kneighbors()

        # Calculate labels based on nearest neighbors
        knn_labels = np.zeros_like(true_labels)
        for i, neighbors in enumerate(indices):
            neighbor_labels = true_labels[neighbors]
            knn_labels[i] = np.bincount(neighbor_labels).argmax()

        # Compute silhouette score
        silhouette = silhouette_score(images_pca, knn_labels)

        # Calculate ARI
        ari = adjusted_rand_score(true_labels, knn_labels)

        # Update best k and best silhouette score
        if silhouette > best_silhouette_score:
            best_k = k
            best_silhouette_score = silhouette
            best_ari = ari

    print(f"Best k value: {best_k}")
    print(f"Best silhouette score: {best_silhouette_score}")
    print(f"Adjusted Rand Index (ARI) for best k: {best_ari}")

    # Predicted labels using majority voting among the k nearest neighbors
    predicted_labels = np.zeros_like(true_labels)

    for i in range(len(images_pca)):
        neighbor_labels = true_labels[indices[i]]
        predicted_labels[i] = np.bincount(neighbor_labels).argmax()

    overall_acc = np.mean(predicted_labels == true_labels)
    print(f"Overall accuracy: {overall_acc:.3f}")

    unique_labels = np.unique(true_labels)
    per_class_acc = {label: np.mean(predicted_labels[true_labels == label] == label)
                     for label in unique_labels}
    print(f"Per-class accuracy: { {k: round(v, 3) for k, v in per_class_acc.items()} }")

    unique_labels = np.unique(true_labels)

    mean_distances_per_label = []
    unique_labels = np.unique(true_labels)

    for label in unique_labels:
        mask = true_labels == label
        distances_for_label = distances[mask]  # Subset of distances for the current label
        mean_distance_for_label = np.mean(distances_for_label)  # Calculate mean distance for the current label
        mean_distances_per_label.append(mean_distance_for_label)

    print(f"Mean distance to neighbours for each score {mean_distances_per_label}")

    class_data = {}  # Dictionary to store data for each class
    for label in unique_labels:
        mask = true_labels == label
        class_data[label] = images_pca[mask]  # Subset of data for the current label

    # Calculate distances between each class
    class_distances = {}
    for label1, data1 in class_data.items():
        for label2, data2 in class_data.items():
            if label1 != label2:
                # Compute distances between each pair of classes
                nbrs.fit(data2)
                distances, _ = nbrs.kneighbors(data1, n_neighbors=1)
                mean_distance = np.mean(distances)
                class_distances[(label1, label2)] = mean_distance


    def plot_class_distances(class_distances):
        unique_labels = np.unique([label for labels in class_distances.keys() for label in labels])

        # Create a matrix to store distances between each class
        distance_matrix = np.zeros((len(unique_labels), len(unique_labels)))

        # Fill the distance matrix
        for (label1, label2), distance in class_distances.items():
            distance_matrix[label1, label2] = distance

        # Create a heatmap

        plt.yticks(np.arange(len(unique_labels)), unique_labels)

        plt.ylabel('Class')
        plt.title('Distances between Classes')
        plt.savefig(str(plots_dir / f"knn_class_distances_{name}.png"), dpi=300, bbox_inches='tight')
        plt.show()

    plot_class_distances(class_distances)

    # Scatter plot of predicted cluster assignments
    plt.figure(figsize=(8, 6))
    unique_labels_pred = np.unique(predicted_labels)

Question: What do the silhouette scores tell us about how the images are clustering?

Answer: Silhouette scores lie between -1 and 1, and denote how close each image is to others of its own cluster vs adjacent clusters. The best average silhouette score was -0.012 for a k value of 9. This is roughly zero, and indicates on average each image is close to the decision boundary between two clusters. This value indicates that the average distance between the points in one cluster are roughly equal to the average distance between them and the adjacent cluster.

Question: Do adjacent scores cluster more closely than distant ones?

Answer: The heatmap shows that the average distance between clusters increases in all cases when the distance between scores increases.

The ARI is 0.319. This means roughly 32% of the variablility in the clustering assignments can be explained by the true class labels. This means there is some agreement between the clusters assigned based on k-NN and the true labels.
