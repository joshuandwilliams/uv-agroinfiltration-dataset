Average Score by Leaf Position

Date: 21/6/2024

1. GOHREP

Goal:

Visualise the average median CDA score by leaf infiltration position to test for systematic differences across the leaf.

Hypothesis:

Leaf positions closer to the stem will show lower average scores due to physiological differences in cell death susceptibility across the leaf.

Rationale:

The Banfield lab rotates infiltration patterns anti-clockwise across biological replicates to control for leaf position effects. If cell death severity varies systematically by position, this should be visible in the averaged scores.

Position on the leaf varies according to existing research: - https://analyticalsciencejournals.onlinelibrary.wiley.com/doi/10.1002/bit.24523 - https://link.springer.com/article/10.1186/s13007-015-0091-5

Experimental plan:

  1. Generate sector polygon coordinates from a leaf image using benth_outline_python.qmd (run first to produce the sector CSVs).
  2. Average median scores per leaf position for images with 5, 6, and 8 positions.
  3. Plot as a leaf-shaped sector heatmap using the polygon coordinates.

sector_avg_scores <- function(data, num_pos) {
  data %>%
    group_by(Basename) %>%
    filter(max(Pos, na.rm = TRUE) == num_pos) %>%
    ungroup() %>%
    group_by(Pos) %>%
    summarise(Avg_Score = mean(Median_Score, na.rm = TRUE), .groups = "drop")
}

avg_5 <- sector_avg_scores(score_data, 5)
avg_6 <- sector_avg_scores(score_data, 6)
avg_8 <- sector_avg_scores(score_data, 8)

score_lims <- range(c(avg_5$Avg_Score, avg_6$Avg_Score, avg_8$Avg_Score), na.rm = TRUE)

make_leaf_plot <- function(sectors, avg_scores, num_pos, score_lims) {
  n_cdas <- score_data %>%
    group_by(Basename) %>%
    filter(max(Pos, na.rm = TRUE) == num_pos) %>%
    ungroup() %>%
    nrow()

  plot_data <- sectors %>%
    rename(Pos = sector) %>%
    left_join(avg_scores, by = "Pos")

  gx <- mean(plot_data$x)
  gy <- mean(plot_data$y)

  centroids <- plot_data %>%
    group_by(Pos) %>%
    summarise(cx        = mean(x) * 0.7 + gx * 0.3,
              cy        = mean(y) * 0.7 + gy * 0.3,
              Avg_Score = first(Avg_Score),
              .groups   = "drop")

  ggplot(plot_data, aes(x = x, y = y, group = factor(Pos), fill = Avg_Score)) +
    geom_polygon(color = "black") +
    geom_text(data = centroids,
              aes(x = cx, y = cy, label = round(Avg_Score, 2)),
              inherit.aes = FALSE, color = "white", size = 5) +
    scale_fill_gradient(low = "cornflowerblue", high = "firebrick",
                        name = "Avg Median\nScore", limits = score_lims) +
    coord_fixed() +
    labs(title = paste0(num_pos, " positions (n = ", n_cdas, ")")) +
    theme_void() +
    theme(plot.title        = element_text(size = 13, hjust = 0.5),
          legend.title      = element_text(size = 12),
          legend.text       = element_text(size = 10),
          plot.background   = element_rect(fill = "white", colour = NA),
          panel.background  = element_rect(fill = "white", colour = NA))
}

p_leaf <- make_leaf_plot(sectors_5, avg_5, 5, score_lims) +
          make_leaf_plot(sectors_6, avg_6, 6, score_lims) +
          make_leaf_plot(sectors_8, avg_8, 8, score_lims) +
          plot_layout(nrow = 1, guides = "collect")

What this shows:

  • The stem end of the leaf is consistently scored lower than the tip of the leaf.

Discussion:

  • The difference may be due to developmental age gradient (dicot leaves mature basipetally, such that the tip is the oldest). Older, more mature tissue tends to be closer to senescence and has a lower threshold for stress-induced HR cell death.
  • The Buyel and Fischer paper, which measures transient expression, shows higher DsRed yield at the stem / base than the tip, which is an opposite pattern to the cell death scores I’m seeing. DsRed is non-cytotoxic reporter, so the leaves aren’t dying. Their gradient is purely expression-capacity measurement, so they’re measuring different things.
  • Differences between leaf infiltration patterns (5, 6, and 8 positions) are more likely to reflect differences in project.
