3. Score proportions per source image

3.1 Compute proportions

Code 
# 3.1
score_data_grouped <- score_data %>%
  group_by(Basename) %>%
  summarize(
    Frequency_0 = sum(c(Score1, Score2, Score3) == 0, na.rm = TRUE),
    Frequency_1 = sum(c(Score1, Score2, Score3) == 1, na.rm = TRUE),
    Frequency_2 = sum(c(Score1, Score2, Score3) == 2, na.rm = TRUE),
    Frequency_3 = sum(c(Score1, Score2, Score3) == 3, na.rm = TRUE),
    Frequency_4 = sum(c(Score1, Score2, Score3) == 4, na.rm = TRUE),
    Frequency_5 = sum(c(Score1, Score2, Score3) == 5, na.rm = TRUE),
    Frequency_6 = sum(c(Score1, Score2, Score3) == 6, na.rm = TRUE),
    Total = n() * 3
  ) %>%
  mutate(
    Proportion_0 = Frequency_0 / Total,
    Proportion_1 = Frequency_1 / Total,
    Proportion_2 = Frequency_2 / Total,
    Proportion_3 = Frequency_3 / Total,
    Proportion_4 = Frequency_4 / Total,
    Proportion_5 = Frequency_5 / Total,
    Proportion_6 = Frequency_6 / Total
  ) %>%
  rowwise() %>%
  mutate(Most_Common_Score = which.max(c(
    Proportion_0, Proportion_1, Proportion_2, Proportion_3, Proportion_4, Proportion_5, Proportion_6
  )) - 1) %>%
  ungroup()

# Long form: one row per (image, score) with its proportion
score_data_heatmap <- score_data_grouped %>%
  pivot_longer(
    cols = starts_with("Proportion"),
    names_to = "Score",
    values_to = "Proportion"
  ) %>%
  mutate(Score = sub("Proportion_", "", Score))

3.2 Distribution of each score’s proportion across images (violins)

Code 
# 3.2
score_box <- score_data_heatmap %>%
  mutate(Score = factor(Score, levels = as.character(0:6))) %>%
  group_by(Score) %>%
  mutate(is_outlier = Proportion > quantile(Proportion, 0.75) + 1.5 * IQR(Proportion)) %>%
  ungroup()

outlier_counts <- score_box %>%
  group_by(Score) %>%
  summarise(n_out = sum(is_outlier), y_lab = max(Proportion) + 0.04, .groups = "drop")

set.seed(1)
p <- ggplot(score_box, aes(x = Score, y = Proportion)) +
  geom_violin(aes(fill = Score), scale = "width", quantile.linetype = 1) +
  geom_point(
    data = subset(score_box, is_outlier),
    position = position_jitter(width = 0.08, height = 0), size = 0.8, alpha = 0.5
  ) +
  geom_text(
    data = outlier_counts, aes(x = Score, y = y_lab, label = n_out),

4. Interpretation and Discussion

  • Some images had no 0s. This is interesting because there are normally control infiltrations.
  • Some images had almost all 0s.
  • Non-0 scores rarely comprised more than 50% of cell death areas in a source image, with a couple of excepions for 2s and 6s.
  • The images with no 0s are mostly images where two infiltrations were applied to the same leaf. In the case that there was none of the usual green cell death, there was an orange cell death of the other infiltration, and the annotators were instructed to ignore those cell death areas because they did not represent true “no cell death” examples.
  • Like the CDA images themselves, in many of the source agroinfiltration images the most common score was 0.
  • For images where the most common score was 5 or 6, there tended to be very few scores between 1 and 3.
  • For images where the most common score was 3, there tended to be very few extreme scores (0 or 6).
  • The images for which most scores were extreme (0 or 5/6) were likely from biological systems that showed strong presence/absence phenotypes.
  • The images with very few 0s were likely from images where each cell death area received two infiltrations, and those with no green cell death were excluded from annotation.
