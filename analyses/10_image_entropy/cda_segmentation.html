Segmenting cell death area from leaf background

Date: 13/7/2026

GOHREP

Goal:

Test whether the cell death area (CDA) of a leaf can be separated from the healthy leaf background universally — with one method and no per-image manual threshold tuning — using the distribution of pixel values.

Hypothesis:

An earlier attempt (PhD_DL_Models/analyses/0009_Non_DL_Green_Channel_Analysis) watershedded on image brightness/grayscale and found the threshold had to be retuned per image. The reason is colour: under this UV-fluorescence imaging the healthy leaf is red (high R, low G) and cell death is yellow-green (G ≈ or > R), and red leaf and green CDA have similar brightness. Segmenting on a greenness channel (G − R) instead should separate CDA from leaf with a threshold that Otsu can set automatically per image, because the two tissues form distinct modes in greenness even when they do not in brightness.

Rationale:

Otsu’s method finds the threshold that best splits a bimodal distribution. If CDA and leaf are two modes in greenness, Otsu adapts to each image with no manual input. Where there is no CDA (median-0 leaves), there is only one mode, so segmentation is only meaningful once an image is known to be non-zero — hence 0 and non-0 are treated separately here.

# 1.3
load_img <- function(path) {
  img <- readTIFF(path, info = FALSE)
  if (length(dim(img)) == 2) img <- array(img, dim = c(dim(img), 3))
  img[, , 1:3, drop = FALSE]
}

# Leaf mask: non-black pixels (drops background and holes), as in the main
# analysis (10_image_entropy §5.5).
leaf_mask <- function(img) (img[, , 1] + img[, , 2] + img[, , 3]) / 3 >= 0.10

# Greenness channel: green minus red. Healthy (red) leaf is strongly negative;
# yellow-green CDA is near zero or positive.
greenness <- function(img) img[, , 2] - img[, , 1]

# Otsu threshold on a value vector, plus the "separability" = between-class
# variance at the threshold / total variance (a 2-class eta^2 in [0,1]). High
# separability => the values are well split into two modes (bimodal).
otsu_sep <- function(x, nbins = 64) {
  rng <- range(x)
  if (diff(rng) < 1e-6) return(c(thr = rng[1], sep = 0, frac_hi = 0))
  br <- seq(rng[1], rng[2], length.out = nbins + 1)
  mids <- (br[-1] + br[-length(br)]) / 2
  h <- tabulate(cut(x, br, include.lowest = TRUE), nbins)
  p <- h / sum(h)
  mu <- sum(p * mids)
  tot <- sum(p * (mids - mu)^2)
  w1 <- cumsum(p); m1 <- cumsum(p * mids)
  bcv <- (mu * w1 - m1)^2 / (w1 * (1 - w1) + 1e-12)
  k <- which.max(bcv)
  c(thr = br[k + 1], sep = max(bcv) / (tot + 1e-12), frac_hi = mean(x > br[k + 1]))
}

# Full spatial segmentation of one image: Otsu on the (blurred) greenness within
# the leaf, followed by morphological cleanup.
segment_cda <- function(img, sigma = 2) {
  leaf <- leaf_mask(img)
  g <- greenness(img)
  gs <- (g - min(g)) / (max(g) - min(g) + 1e-9) # rescale to 0-1 for EBImage
  gb <- EBImage::gblur(gs, sigma = sigma)
  thr <- EBImage::otsu(matrix(gb[leaf]), range = c(0, 1))
  mask <- leaf & (gb > thr)
  mask <- EBImage::fillHull(EBImage::opening(mask, EBImage::makeBrush(5, "disc")))
  # Keep only the largest connected component, dropping small floating islands.
  lab <- EBImage::bwlabel(mask)
  if (max(lab) > 1) mask <- lab == which.max(tabulate(lab[lab > 0]))
  list(leaf = leaf, greenness = gb, mask = mask, cda_frac = mean(mask))
}

# Overlay a mask on an image by turning masked pixels yellow-magenta.
overlay <- function(img, mask, colour = c(1, 0, 1)) {
  out <- img
  for (k in 1:3) { ch <- out[, , k]; ch[mask] <- colour[k]; out[, , k] <- ch }
  out
}

# Bold column headers (top) and rotated row labels (left) for the base-graphics
# example grids, drawn once into the outer margins instead of per-panel titles.
colhead <- function(labels, ncol, cex = 1)
  for (c in seq_along(labels))
    mtext(labels[c], side = 3, outer = TRUE, line = 0.3, at = (c - 0.5) / ncol,
          font = 2, cex = cex)
rowlab <- function(label, r, nrow, cex = 1)
  mtext(label, side = 2, outer = TRUE, las = 0, line = 1,
        at = 1 - (r - 0.5) / nrow, cex = cex)

# Draw a coloured outline of a mask onto an image (a boundary band of the given
# half-width), leaving the interior visible - clearer than a filled overlay.
outline <- function(img, mask, colour = c(0.12, 0.56, 1), width = 2) {
  br <- EBImage::makeBrush(2 * width + 1, "disc")
  edge <- EBImage::dilate(mask, br) & !EBImage::erode(mask, br)
  out <- img
  for (k in 1:3) { ch <- out[, , k]; ch[edge] <- colour[k]; out[, , k] <- ch }
  out
}

2. Why brightness fails and greenness works

For one low- and one high-score CDA, the brightness of the leaf and the CDA overlap (a single smeared mode), while in greenness the CDA and leaf separate into two modes. This is why an Otsu/watershed threshold on brightness cannot be set once and reused, but one on greenness can.

4. Can the distribution alone detect whether a CDA is present?

Segmenting assumes a CDA exists. The natural universal test for “is there a CDA” is the bimodality (separability) of the leaf-greenness distribution. The following computes, for every image, the eleven region features summarised from the segmentation (§6.1), including the leaf-greenness separability. Computed once and cached.

Code 
# 5.1
cache_path <- here("analyses", "10_image_entropy", "entropy_cache",
                   "cda_segmentation_metrics.rds")

if (file.exists(cache_path)) {
  seg <- readRDS(cache_path)
} else {
  scores <- list.dirs(data_dir, recursive = FALSE, full.names = FALSE)
  scores <- scores[grepl("^[0-9]+$", scores)]
  rows <- list()
  for (sc in scores) {
    files <- list.files(file.path(data_dir, sc), pattern = "\\.tif$", full.names = TRUE)
    m <- t(vapply(files, function(f) {
      # All region features are read off the SAME segmentation: the leaf mask,
      # the spatial CDA mask from segment_cda() (Otsu on blurred greenness ->
      # morphological cleanup -> largest connected component), and the healthy
      # leaf (leaf minus CDA). Nothing is re-thresholded per feature.
      img <- load_img(f)
      s       <- segment_cda(img)
      leaf    <- s$leaf                    # leaf region ((R+G+B)/3 >= 0.10)
      cda     <- s$mask & leaf             # segmented CDA (largest greenness component)
      healthy <- leaf & !cda               # healthy leaf = leaf minus CDA
      gmat <- greenness(img)               # greenness G - R over the whole image
      bmat <- (img[, , 1] + img[, , 2] + img[, , 3]) / 3   # brightness (mean RGB)
      R <- img[, , 1]; G <- img[, , 2]
      nsd <- function(x) if (length(x) > 1) sd(x) else 0
      mn  <- function(x) if (length(x))  mean(x) else 0

      gv_leaf <- gmat[leaf]                # greenness over the whole leaf
      o <- otsu_sep(gv_leaf)               # separability (bimodality) of leaf greenness
      n_green <- sum(G[leaf] >= R[leaf]); n_red <- sum(R[leaf] > G[leaf])  # colour counts over leaf

      c(sep           = unname(o["sep"]),                             # 4  leaf-greenness bimodality
        green_gap     = if (any(cda) && any(healthy))                 # 3  CDA vs healthy-leaf greenness
                          mean(gmat[cda]) - mean(gmat[healthy]) else 0,
        cda_green     = mn(gmat[cda]),                                # 2  CDA greenness
        frac_g_gt_r   = sum(cda) / sum(leaf),                         # 1  lesion size = |CDA| / |leaf|
        cda_green_sd  = nsd(gmat[cda]) * 255,                         # 7  within-CDA greenness spread
        cda_bright    = mn(bmat[cda]) * 255,                          # 5  CDA brightness
        cda_bright_sd = nsd(bmat[cda]) * 255,                         # 8  within-CDA brightness spread
        leaf_green_sd = nsd(gv_leaf) * 255,                           # 6  whole-leaf greenness spread
        mean_green    = mn(G[leaf]) * 255,                            # 10 mean green over leaf
        log_gr        = log((n_green + 1) / (n_red + 1)),             # 9  log green:red count over leaf
        leaf_bright   = mn(bmat[leaf]) * 255)                         # 11 leaf brightness
    }, numeric(11)))
    rows[[sc]] <- data.frame(image_id = tools::file_path_sans_ext(basename(files)),
                             score = as.integer(sc), m, row.names = NULL)
    message(sprintf("score %s done (%d)", sc, length(files)))
  }
  seg <- dplyr::bind_rows(rows)
  saveRDS(seg, cache_path)
}

# Rank-based (Mann-Whitney) AUC: probability a random non-0 image scores higher
# than a random 0 image on the given feature.
auc <- function(feature, positive) {
  r <- rank(feature)
  n_pos <- sum(positive); n_neg <- sum(!positive)
  (sum(r[positive]) - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
}

6. Predicting score from the hand-crafted features

Can these hand-crafted features predict a CDA’s score? All modelling here uses a class-balanced dataset — every score downsampled to the smallest class — so the abundant score-0 class cannot dominate (the same balancing used in 07_visual_complexity and the AutoCDAScorer ensemble analysis). Because the classes are equal, a majority-class guess scores only 1/7 and exact accuracy equals balanced accuracy. Accuracy is reported as exact (predicted = true), near-miss (within ±1, as in 07_visual_complexity), and balanced (mean of the per-class exact accuracies).

The full pipeline, end to end, for one cropped CDA image:

  1. Load the raw RGB crop (no resizing — the features are scale-free).
  2. Leaf mask — keep pixels with mean brightness ≥ 0.1 (§1.3).
  3. Segment the CDA — Otsu threshold on the blurred leaf greenness (G − R), morphological cleanup, then keep the largest connected component (§3).
  4. Summarise the crop into 12 scalar features (§6.1).
  5. Predict the 0–6 score from those features (random forest, k-NN or ordinal regression). No per-image threshold tuning anywhere.

The twelve features — all per-image summaries of the raw crop, so they can be read directly off the importance (§6.6) and SHAP (§6.7) plots. “Greenness” means G − R (green minus red channel); the “CDA” is the segmented cell-death region (the largest connected greenness component after Otsu thresholding and morphological cleanup, §3); the “leaf” is all non-black pixels (§1.3); the “healthy leaf” is the leaf minus the CDA.

6.1 Assemble features, and a leakage-safe cross-validation

Each cropped CDA comes from a source leaf image (~29 crops per leaf). Crops from the same leaf share lighting, plant and tissue, so they are correlated; splitting them across training and test folds would leak information and inflate accuracy. All cross-validation here is therefore grouped by source leaf — whole leaves are assigned to folds, so no leaf ever appears in both training and test. (Ungrouped image-level CV gives ~0.58 exact; grouping removes the leak and gives the honest ~0.55.) A shuffled-label check (§6.1) confirms the pipeline has no other leakage.

  per <- vapply(0:6, function(s) mean(pred[y == s] == s), numeric(1))
  data.frame(model = name, tuning = tuning,
             exact = mean(pred == y), near_miss = mean(abs(pred - y) <= 1),

               exact = mean(pred[m] == y[m]),
               near_miss = mean(abs(pred[m] - y[m]) <= 1)) }))

# 7.1.3  Random-forest regressor under the grouped CV, plus a leakage sanity check.
rf_reg_cv <- function(ntree, target = y) {
  pred <- numeric(length(target))
  for (f in 1:K) {
    tr <- fold != f; te <- fold == f

6.2 Choosing k for k-NN

k is swept over a range and chosen by grouped cross-validated exact accuracy (the supervised analogue of the k-selection in 07_visual_complexity). Held-out accuracy is essentially flat beyond k ≈ 5, so the precise value barely matters; it is taken as the CV maximum for definiteness. (Only held-out accuracy is shown — training-set accuracy is meaningless for k-NN, since at k = 1 each point is its own neighbour and scores 100% by construction.)

Code 
# 7.2.1
knn_cv <- function(ks) {
  P <- matrix(0L, nrow(X), length(ks), dimnames = list(NULL, paste0("k", ks)))
  for (f in 1:K) {
    tr <- fold != f; te <- fold == f
    mu <- colMeans(X[tr, ]); sdv <- apply(X[tr, ], 2, sd); sdv[sdv == 0] <- 1
    Xtr <- scale(X[tr, , drop = FALSE], mu, sdv)
    Xte <- scale(X[te, , drop = FALSE], mu, sdv)
    d <- outer(rowSums(Xte^2), rowSums(Xtr^2), "+") - 2 * Xte %*% t(Xtr)
    ytr <- y[tr]; ord <- t(apply(d, 1, order))
    for (j in seq_along(ks)) {
      P[te, j] <- apply(ord[, 1:ks[j], drop = FALSE], 1, function(ix) {
        tb <- table(ytr[ix]); as.integer(names(tb)[which.max(tb)])
      })
    }
  }
  P
}

6.3 Random forest: regularising to control overfitting

A fully-grown random forest memorises the training set — its training accuracy is ~0.91 against ~0.55 held-out, a ~36-point gap — so by the rule of discarding any model whose train–test gap exceeds 15%, it must be regularised. The forest is fixed at 200 trees (accuracy plateaus well before that, and more trees never hurt a random forest) and the tree size is capped with maxnodes, increasing it until the train–test gap reaches 15%; the largest held-out accuracy within that bound is chosen. Training accuracy is fit and scored on all the data (resubstitution); held-out is the grouped 5-fold CV.

Code 
# 7.3.1
NTREE <- 200
rf_fit_cv <- function(maxnodes) {           # grouped-CV (held-out) predictions
  pred <- numeric(length(y))
  for (f in 1:K) {
    tr <- fold != f; te <- fold == f
    m <- randomForest::randomForest(x = X[tr, , drop = FALSE], y = y[tr],
                                    ntree = NTREE, maxnodes = maxnodes)

  }

}

6.4 Model comparison, with per-fold results

The tuned models are compared with a majority-class baseline and a single-feature threshold rule, all under the same grouped 5-fold CV. Both training (fit and scored on all the data) and held-out (grouped CV) accuracy are reported for every model, with the gap between them; any model whose gap exceeds 15% is flagged for discarding as overfit (only the fully-grown forest of §6.3 fails — every tuned model here passes).

Code 
# 7.4.1
# Held-out (grouped CV) predictors
thresh_cv <- function(x) {
  pred <- integer(length(y))
  for (f in 1:K) {
    tr <- fold != f; te <- fold == f
    med <- tapply(x[tr], y[tr], median)
    sc <- as.integer(names(med)); o <- order(sc); med <- med[o]; sc <- sc[o]
    cuts <- cummax((head(med, -1) + tail(med, -1)) / 2)
    pred[te] <- sc[findInterval(x[te], cuts) + 1]
  }
  pred
}
ord_cv <- function() {
  pred <- integer(length(y))
  for (f in 1:K) {
    tr <- fold != f; te <- fold == f
    mu <- colMeans(X[tr, ]); sdv <- apply(X[tr, ], 2, sd); sdv[sdv == 0] <- 1
    dtr <- data.frame(scale(X[tr, , drop = FALSE], mu, sdv),
                      y = factor(y[tr], levels = 0:6, ordered = TRUE))
    dte <- data.frame(scale(X[te, , drop = FALSE], mu, sdv))
    fit <- suppressWarnings(MASS::polr(y ~ ., data = dtr, Hess = TRUE))
    pred[te] <- as.integer(as.character(predict(fit, dte, type = "class")))
  }
  pred
}

7. PCA of the image content, with and without the background

07_visual_complexity runs a principal component analysis (PCA) on the CDA images and colours the first two components by severity score. Both PCAs use the same class-balanced sample (the smallest class’s size per score), the same 64 × 64 pixel normalised inputs, and the same severity-score colouring; the only difference is whether the background is masked out.

8. Interpretation and Discussion

  • Greenness solves the universal-threshold problem. Switching the segmentation channel from brightness to greenness (G − R) makes CDA and leaf distinct modes, so Otsu sets the threshold automatically per image with no manual tuning (§2–§3). This is the fix for the failure in 0009_Non_DL_Green_Channel_Analysis, where brightness watershedding needed a different threshold for every image.
  • Presence detection works, but segment conditionally. The bimodality (separability) of the leaf-greenness distribution classifies 0 vs non-0 well on its own (AUC ≈ 0.94, §4.2), so the distribution does detect whether a CDA is present — confirming this is the easy part of the problem. But if the spatial Otsu segmentation is run unconditionally it still outlines a spurious region on a median-0 leaf (§3), so segmentation should be gated on the non-0 decision, as hypothesised.
  • The features predict score to ±1 reliably, but the exact score only about half the time (§6). All modelling is on the class-balanced data (436/class), so there is no score-0 free ride and exact = balanced accuracy, and all accuracy is measured with source-grouped 5-fold CV (a leaf’s crops are never split across folds; an image-level split leaks ~2–3 points, §6.1). A shuffled-label check collapses to chance, confirming no other leakage. The tuned models cluster tightly at ~54% held-out exact and ~95% near-miss: a regularised random forest (tree size capped so the train–test gap stays under 15%, §6.3), a k-NN (k = 25, chosen by CV) and — just as good — a linear ordinal regression, whose train–test gap is essentially zero. A single-feature threshold rule reaches ~37%. The confusion matrix is a tight band-diagonal (errors almost entirely between adjacent scores; score 1 mostly confused with 0 and 2), so the features locate a CDA to within ±1 of its score almost always but cannot pin the exact neighbouring severity. An unregularised forest reaches ~91% training accuracy but the same ~55% held-out — pure memorisation (a ~36-point gap), so it is discarded; regularising costs almost nothing in held-out accuracy. For reference (not a like-for-like comparison), the project’s deep-learning models reach ~70% training and 60–67% held-out test — a small gap and higher test accuracy than these hand-crafted features.
  • Gini importance and SHAP agree on what matters (§6.6–6.7). CDA area (frac_g_gt_r), CDA greenness, the green/red ratio, CDA brightness and greenness bimodality drive the predictions. The SHAP beeswarm shows high values of these features push the prediction toward higher scores, consistently across images rather than as narrow high- or low-severity specialists; the dependence plots show mostly monotonic (area saturating) effects, and the within-CDA texture features (cda_green_sd, cda_bright_sd) sit near zero — how mottled a lesion is matters far less than how large, green and bright it is.
  • Low scores remain hard. At scores 1–2 the CDA is barely greener than the leaf, so the modes overlap and the segmentation features overlap the neighbouring classes (§5, §6). This is the same faint-signal regime that limits every hand-crafted feature in 10_image_entropy — mild cell death is genuinely close to healthy tissue in these images, which is why a learned model is needed to resolve the fine-grained scores.
