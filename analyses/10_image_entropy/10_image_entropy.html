Image information and input size selection

Date: 13/7/2026

GOHREP

Goal:

  1. Measure how much image information (Shannon entropy) each cropped CDA image retains as it is downsampled to progressively smaller side lengths, in order to justify a standardised input size for model training.
  2. Characterise how Shannon entropy, the green/red colour balance, and the mean green level of a CDA relate to its severity score.

Hypothesis:

  1. Shannon entropy stays roughly constant from the raw crop down to a moderate side length, then falls once the image becomes too small to hold the same range of pixel intensities. A side length just above that drop-off preserves almost all of the information while minimising the number of pixels (and therefore the training compute).
  2. Under the UV-fluorescence imaging used here, healthy tissue autofluoresces red and cell death shifts the balance towards green, so the green/red ratio and the mean green level should both increase with severity score. Shannon entropy alone is expected to overlap heavily between scores.

Rationale:

Downsampling reduces the number of pixels and therefore the number of distinct intensity values an image can represent, which caps its Shannon entropy. If entropy is preserved down to a given side length, that size still carries the information a model could use; shrinking further discards information. Locating the side length at which entropy begins to fall gives a principled, information- theoretic basis for choosing the input resolution (64 × 64 px) used elsewhere in this project (see 07_visual_complexity).

This analysis reproduces, for the full multi-set dataset, figures first made on Set 1 alone during the Year 1 probationary review.

1.3 Configuration and metric functions

Code 
# 1.3
# Cropped CDA images are stored one folder per median severity score (0-6);
# the folder name is the score. Each image is resized to a range of square
# side lengths and its Shannon entropy computed at every size. "Raw" is the
# original crop (variable native size, see 07_visual_complexity).
data_dir <- here("data", "cropped_images")
sizes <- c(128, 64, 32, 16, 8, 4)
size_levels <- c("Raw", as.character(sizes)) # x-axis order: large -> small

# Shannon entropy of an image, replicating the default behaviour of
# skimage.measure.shannon_entropy used in the original Year 1 analysis:
# histogram every value in the array (flattened across the RGB channels) as an
# 8-bit intensity, then H = -sum(p_i * log2(p_i)). More distinct, evenly used
# intensities -> higher entropy; the maximum is 8 bits.
shannon_entropy <- function(arr) {
  v <- as.integer(round(pmin(pmax(arr, 0), 1) * 255))
  counts <- tabulate(v + 1L, nbins = 256L)
  p <- counts[counts > 0] / length(v)
  -sum(p * log2(p))
}

# Per-image metrics: entropy at every side length, plus two colour metrics
# computed on the raw crop over non-dark pixels (max(R,G,B) >= 0.1, which
# excludes the black background and holes in the leaf, as in the original).
#   - log_gr: log of the green:red pixel-count ratio. Under this imaging
#     healthy tissue is red and cell death shifts towards green, so this is
#     expected to rise with score. A +1 pseudocount avoids log(0).
#   - mean_green: mean green-channel intensity (0-255) of the non-dark pixels.
image_metrics <- function(path) {
  img <- readTIFF(path, info = FALSE)
  if (length(dim(img)) == 2) img <- array(img, dim = c(dim(img), 3))
  img <- img[, , 1:3, drop = FALSE]

  ent <- c(Raw = shannon_entropy(img))
  for (s in sizes) {
    r <- pmin(pmax(EBImage::resize(img, w = s, h = s), 0), 1)
    ent[as.character(s)] <- shannon_entropy(r)
  }

  R <- img[, , 1]; G <- img[, , 2]; B <- img[, , 3]

  # Non-dark pixels (drops black background/holes) for the colour metrics.
  nondark <- pmax(R, G, B) >= 0.1
  n_red <- sum(R[nondark] > G[nondark])
  n_green <- sum(G[nondark] >= R[nondark])

  # Per-pixel brightness and two leaf-region definitions (see 5.5):
  #  - otsu_*: an image-adaptive two-class threshold (Otsu, from the image's
  #    own brightness histogram). It cleanly removes a dark background but, in
  #    high-score CDAs, tends to select the bright lesion rather than the whole
  #    leaf, so it is used only to illustrate that difficulty.
  #  - leaf_*: a low fixed cut that removes only the near-black background,
  #    keeping all tissue - a less score-dependent lighting proxy.
  bright_px <- (R + G + B) / 3
  thr <- EBImage::otsu(bright_px, range = c(0, 1))
  otsu_mask <- bright_px > thr
  if (sum(otsu_mask) < 0.02 * length(otsu_mask)) otsu_mask <- bright_px >= 0.1
  leaf_mask <- bright_px >= 0.10

  c(ent,
    log_gr = log((n_green + 1) / (n_red + 1)),
    mean_green = mean(G[nondark]) * 255,
    otsu_frac = mean(otsu_mask),
    otsu_bright = mean(bright_px[otsu_mask]) * 255,
    leaf_frac = mean(leaf_mask),
    leaf_bright = mean(bright_px[leaf_mask]) * 255)
}

5.4 Lighting-normalised green level by score

To remove the between-project lighting offset seen in §5.3, each CDA’s green level is centred on its project mean and shifted back to the global mean (green_norm = green - project_mean + global_mean). This corrects for per-project brightness without touching the score differences that exist within a project. The two panels below compare raw and project-normalised green by score.

The correction is applied at project level rather than per source image on purpose: an individual source image holds only ~30 CDAs whose scores are correlated, so its own green mean partly encodes score, and normalising there removes real signal (η² below). A project spans many source images and the full score range, so its mean is a cleaner estimate of the lighting baseline.

Code 
# 5.4.1
global_mean_green <- mean(per_image$mean_green)

  ungroup() %>%
  group_by(source) %>%
  mutate(green_norm_source = mean_green - mean(mean_green) + global_mean_green) %>%

# eta^2: fraction of green variance explained by score. Higher = scores more
# separable. Compared across raw green and the two normalisation levels.
eta_sq <- function(y, g) {
  grand <- mean(y)
  ss_between <- sum(tapply(y, g, function(v) length(v) * (mean(v) - grand)^2))
  ss_between / sum((y - grand)^2)
}

5.5 Isolating the leaf region to estimate lighting

The green normalisation in §5.4 uses green to estimate lighting, which is circular. A cleaner lighting proxy is the brightness of the leaf itself (mean of the R, G, B channels), measured only over leaf pixels so that the black background — including holes and cell-death voids at the leaf edge — does not drag the estimate down.

To decide which pixels are leaf, two thresholds on each CDA’s own brightness histogram are compared:

  • Otsu — the image-adaptive threshold that maximises between-class variance, i.e. the natural split in the brightness distribution.
  • Leaf (background-only cut) — a low fixed cut (brightness ≥ 0.1) that removes only the near-black background and keeps all tissue.

The panels below show, for one CDA per score, the original crop, the Otsu mask, and the background-only leaf mask.

Code 
# 5.5.1
set.seed(7)
seg_examples <- lapply(c(0, 2, 4, 6), function(sc) {
  f <- sample(list.files(file.path(data_dir, sc), pattern = "\\.tif$",
                         full.names = TRUE), 1)
  img <- readTIFF(f, info = FALSE)
  if (length(dim(img)) == 2) img <- array(img, dim = c(dim(img), 3))
  img <- img[, , 1:3, drop = FALSE]
  bright_px <- (img[, , 1] + img[, , 2] + img[, , 3]) / 3
  thr <- EBImage::otsu(bright_px, range = c(0, 1))
  otsu_mask <- bright_px > thr
  if (sum(otsu_mask) < 0.02 * length(otsu_mask)) otsu_mask <- bright_px >= 0.1
  leaf_mask <- bright_px >= 0.10
  list(sc = sc, img = img, otsu = otsu_mask, leaf = leaf_mask,
       otsu_frac = mean(otsu_mask), leaf_frac = mean(leaf_mask))
})

6. Interpretation and Discussion

  • Input size. Shannon entropy is preserved from the raw crop down to about 16 px and only falls substantially at 8 and 4 px (§3.1–3.3). 64 × 64 px therefore retains essentially all of the information in the raw crops while keeping the pixel count — and the training compute — low, supporting the 64 × 64 input size used for model training (see 07_visual_complexity).
  • Entropy and score. Entropy overlaps heavily between adjacent scores (§4.1), so it is not a usable single feature for classifying severity.
  • Colour and score. Both the green:red ratio (§5.1) and the mean green level (§5.2) increase monotonically with severity, and colour is only weakly correlated with entropy (§5.7) — colour carries score information that entropy does not.
  • Lighting is a real but only partly removable confound. Green level varies between projects (§5.3; ~16% of green variance is between-project), confirming that imaging/lighting differences add noise on top of the score signal. Three intuition-led corrections were tried:
    • Centring green on the project mean (§5.4): removes the offset and modestly tightens the within-score spread, but the gain is small because green’s score signal is partly correlated with which project a CDA is from.
    • Source-image centring (§5.4): over-corrects — a source image’s own green mean partly encodes the scores of its ~30 CDAs — so it removes real signal.
    • Segmenting the leaf and normalising green by leaf brightness (§5.5–5.6): the best proxy, because leaf brightness is far less score-driven than an Otsu foreground (which latches onto the lesion) and carries more between-project variation than green. This gives the largest improvement (η² ≈ 0.52 → 0.58).
  • The features are not enough. Even the best lighting-corrected single feature still leaves neighbouring severity classes heavily overlapped (§5.6). Hand-engineered colour/brightness/entropy features capture part of the severity signal but cannot cleanly separate adjacent scores — the motivation for a learned model over hand-crafted features. ```
