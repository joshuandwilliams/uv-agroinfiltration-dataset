Predicting cell death severity from hand-crafted image features

Date: 13/7/2026

GOHREP

Goal:

Test how well a CDA’s 0-6 severity score can be predicted from twelve hand-crafted image features, and find which of those features carry the signal.

Hypothesis:

The features are summaries of colour, brightness, texture and lesion geometry that a human rater plausibly uses, and each one rises with severity, so a simple model over the twelve should recover the score far better than chance. But because no single feature separates neighbouring scores (adjacent-class AUC peaks at 0.68 in 10_segmentation_and_feature_extraction), the models are expected to place a CDA in roughly the right region of the scale while failing to pin the exact score.

Rationale:

The features are extracted in 10_segmentation_and_feature_extraction and written to data/features/cda_image_features.csv. This analysis starts from that table and does nothing but model it. Three model families are fitted so the result is not an artefact of one inductive bias: k-NN (local, no assumed form), a random forest (non-linear, interaction-capable) and proportional-odds ordinal regression (linear, and the only one that uses the fact the scale is ordered). Each is scored under the same source-grouped cross validation, compared against a majority-class baseline and a single-feature threshold rule, and the winner is attributed with Gini importance and SHAP.

2. Features, class balance and a leakage-safe cross-validation

All modelling uses a class-balanced dataset, every score downsampled to the smallest class, so the abundant score-0 class cannot dominate. Because the classes are equal, a majority-class guess scores 1/7 and exact accuracy equals balanced accuracy. Accuracy is reported as exact (predicted = true), near-miss (within one point) and balanced (mean of the per-class exact accuracies).

The input is one row per cropped CDA image, read from data/features/cda_image_features.csv. Each feature is a scalar summary of the raw crop computed with no per-image threshold tuning, defined in full by 10_segmentation_and_feature_extraction. The “CDA” is the segmented cell-death region, the “leaf” is all non-black pixels, and “greenness” means G - R (green minus red channel).

  • A shuffled-label run returns 0.146 against a 0.143 chance level, so the pipeline carries no leakage of its own.

metric_row <- function(pred, name, tuning = "") {
  per <- vapply(0:6, function(s) mean(pred[y == s] == s), numeric(1))
  data.frame(
    model = name, tuning = tuning,
    exact = mean(pred == y), near_miss = mean(abs(pred - y) <= 1),
    balanced = mean(per)
  )
}
# Per-fold accuracy, so the cross-validation is fully transparent (reported
# alongside the mean, not just pooled).
per_fold <- function(pred, name) {
  do.call(rbind, lapply(1:K, function(f) {
    m <- fold == f
    data.frame(
      model = name, fold = as.character(f), n = sum(m),
      exact = mean(pred[m] == y[m]),
      near_miss = mean(abs(pred[m] - y[m]) <= 1)
    )
  }))
}

# 2.3  Random-forest regressor under the grouped cross validation, plus a leakage sanity check.
rf_reg_cv <- function(ntree, target = y) {
  pred <- numeric(length(target))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    m <- randomForest::randomForest(x = X[tr, , drop = FALSE], y = target[tr], ntree = ntree)
    pred[te] <- predict(m, X[te, , drop = FALSE])
  }
  pmin(pmax(round(pred), 0), 6)
}

3. Choosing k for k-NN

Only held-out accuracy is shown, since at k = 1 each training point is its own neighbour and scores 100% by construction.

  • Held-out accuracy climbs from 0.462 at k = 1 to 0.556 at k = 27, so single nearest neighbours overfit the local noise and averaging fixes it.
  • Every k from 5 upward lands between 0.511 and 0.556, so the exact choice of k matters far less than the ceiling the feature space imposes.
Code 
# 3.1
knn_cv <- function(ks) {
  P <- matrix(0L, nrow(X), length(ks), dimnames = list(NULL, paste0("k", ks)))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    mu <- colMeans(X[tr, ])
    sdv <- apply(X[tr, ], 2, sd)
    sdv[sdv == 0] <- 1
    Xtr <- scale(X[tr, , drop = FALSE], mu, sdv)
    Xte <- scale(X[te, , drop = FALSE], mu, sdv)
    d <- outer(rowSums(Xte^2), rowSums(Xtr^2), "+") - 2 * Xte %*% t(Xtr)
    ytr <- y[tr]
    ord <- t(apply(d, 1, order))
    for (j in seq_along(ks)) {
      P[te, j] <- apply(ord[, 1:ks[j], drop = FALSE], 1, function(ix) {
        tb <- table(ytr[ix])
        as.integer(names(tb)[which.max(tb)])
      })
    }
  }
  P
}
kseq <- seq(1, 51, by = 2)
knn_preds <- knn_cv(kseq)
knn_curve <- data.frame(
  k = kseq,
  exact = apply(knn_preds, 2, function(p) mean(p == y)),
  near_miss = apply(knn_preds, 2, function(p) mean(abs(p - y) <= 1))
)
best_k <- kseq[which.max(knn_curve$exact)]
cat(sprintf(
  "Best k = %d  (held-out exact = %.3f, near-miss = %.3f)\n",
  best_k, max(knn_curve$exact), knn_curve$near_miss[knn_curve$k == best_k]
))

4. Random forest: regularising to control overfitting

The forest is fixed at 200 trees and tree size is capped with maxnodes, taking the largest held-out accuracy whose train-to-held-out gap stays within 15 points. Training accuracy is fit and scored on all the data, held-out is the grouped 5-fold cross validation.

  • Capping trees at 128 leaf nodes reaches 0.562 held-out for a gap of 0.109, while 256 nodes adds only 0.010 held-out accuracy for a 0.168 gap that breaks the 15-point rule.
  • Training accuracy keeps climbing (0.370 to 0.741 across the sweep, and 0.924 fully grown) while held-out accuracy stalls near 0.57, so the extra capacity is memorisation rather than signal.
Code 
# 4.1
NTREE <- 200
rf_fit_cv <- function(maxnodes) { # grouped cross validation (held-out) predictions
  pred <- numeric(length(y))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    m <- randomForest::randomForest(
      x = X[tr, , drop = FALSE], y = y[tr],
      ntree = NTREE, maxnodes = maxnodes
    )
    pred[te] <- predict(m, X[te, , drop = FALSE])
  }
  pmin(pmax(round(pred), 0), 6)
}
rf_fit_train <- function(maxnodes) { # resubstitution (training) predictions
  set.seed(1)
  m <- randomForest::randomForest(x = X, y = y, ntree = NTREE, maxnodes = maxnodes)
  pmin(pmax(round(predict(m, X)), 0), 6)
}
maxnodes_grid <- c(4, 8, 16, 32, 64, 128, 256)
set.seed(42)
reg_curve <- data.frame(
  maxnodes = maxnodes_grid,
  train = sapply(maxnodes_grid, function(mn) mean(rf_fit_train(mn) == y)),
  cross_validation = sapply(maxnodes_grid, function(mn) mean(rf_fit_cv(mn) == y))
)
reg_curve$gap <- reg_curve$train - reg_curve$cross_validation
best_maxnodes <- max(reg_curve$maxnodes[reg_curve$gap <= 0.15])
cat(sprintf(

4.1 Does the tree count matter?

The 200 trees above are asserted rather than tuned, so the sweep is repeated across tree counts. Unlike maxnodes, the number of trees is not a capacity parameter. A random forest averages independently grown trees, and its generalisation error converges as trees are added rather than degrading (Breiman 2001), so more trees should buy variance reduction and nothing else. If that holds, the table below is flat along its rows and the chosen maxnodes does not depend on the tree count.

  • Held-out accuracy climbs by up to 0.014 between 25 and 100 trees, then moves by at most 0.007 out to 800, against a 0.005 spread from merely re-seeding a single setting, so the plateau arrives by roughly 100 trees.
  • The best cap is 256 leaf nodes in all six columns, so the two settings do not interact and the chosen maxnodes would be identical at any tree count.
  • 200 trees therefore sits comfortably past the plateau, and a full two-dimensional search would cost six times the compute to return the same model.

5. Ordinal regression

Proportional-odds ordinal logistic regression fits one linear predictor to the 12 features and six ordered cut-points that split it into the seven classes, so the model uses the ordering of the scale rather than treating the classes as unrelated labels. It has no hyperparameter, so there is no sweep.

  • Held-out exact accuracy is 0.615 against 0.616 training, a gap of 0.002, so twelve coefficients plus six cut-points leave nothing to memorise.
  • Near-miss accuracy is 0.978, so all but 2% of crops land within one point of the true score.
Code 
# 5.1  Ordinal logistic regression (proportional odds, MASS::polr), scored under
# the same source-grouped cross validation. Features are standardised with
# training-fold statistics inside each fold, so nothing leaks into the scaling.
ord_cv <- function() {
  pred <- integer(length(y))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    mu <- colMeans(X[tr, ])
    sdv <- apply(X[tr, ], 2, sd)
    sdv[sdv == 0] <- 1
    dtr <- data.frame(scale(X[tr, , drop = FALSE], mu, sdv),
      y = factor(y[tr], levels = 0:6, ordered = TRUE)
    )
    dte <- data.frame(scale(X[te, , drop = FALSE], mu, sdv))
    fit <- suppressWarnings(MASS::polr(y ~ ., data = dtr, Hess = TRUE))
    pred[te] <- as.integer(as.character(predict(fit, dte, type = "class")))
  }
  pred
}
ord_train <- function() {
  mu <- colMeans(X)
  sdv <- apply(X, 2, sd)
  sdv[sdv == 0] <- 1
  d <- data.frame(scale(X, mu, sdv), y = factor(y, levels = 0:6, ordered = TRUE))
  fit <- suppressWarnings(MASS::polr(y ~ ., data = d, Hess = TRUE))
  as.integer(as.character(predict(fit, data.frame(scale(X, mu, sdv)), type = "class")))
}
ord_best <- ord_cv()
ord_tr <- ord_train()
ord_fmt <- paste0(

5.1 Distribution over 1,000 undersamples

Every accuracy above rests on one balanced undersample drawn at seed 42, which throws away 52% of the crops and could be lucky or unlucky. The whole experiment is therefore repeated 1,000 times, each iteration drawing a fresh undersample of 436 crops per class and a fresh source-grouped fold assignment, then scoring the ordinal regression exactly as above. Both accuracies are held-out: every crop is predicted only while its leaf sits in the held-out fold, and the 3052 out-of-fold predictions are pooled once all five folds are done. This mirrors the repeat stratified undersampling used for the human scoring in 03_human_performance, so the model and the raters are summarised the same way.

  • Across 1,000 undersamples exact accuracy averages 0.608 with a 95% interval of 0.597 to 0.619, so which crops are drawn moves the headline by about a point in either direction.
  • The seed-42 draw used above scores 0.615, the 91st percentile of that distribution, so the single figure quoted for it is mildly lucky rather than typical.
  • Every one of the 1,000 draws still beats the random forest (0.565) and k-NN (0.556), and near-miss accuracy varies by only sd 0.0018, so both the model ranking and the one-point reliability survive resampling.
Code 
# 5.2  1,000 undersamples, each scored by the same grouped 5-fold ordinal
# regression. Cached: the loop takes about 15 minutes.

} else {
  # Seed i drives both the undersample and the fold assignment, so each
  # iteration is an independent repeat of the entire experiment.
  ord_once <- function(seed) {
    set.seed(seed)
    b <- unlist(lapply(0:6, function(s) {
      idx <- which(feat_all$score == s)
      if (length(idx) > min_n) sample(idx, min_n) else idx
    }))
    f <- feat_all[b, ]
    Xi <- as.matrix(f[, all_features])
    yi <- f$score
    u <- unique(f$source)
    fo <- unname(setNames(sample(rep(1:K, length.out = length(u))), u)[f$source])
    pred <- integer(length(yi))
    for (k in 1:K) {
      tr <- fo != k
      te <- fo == k
      mu <- colMeans(Xi[tr, ])
      sdv <- apply(Xi[tr, ], 2, sd)
      sdv[sdv == 0] <- 1
      dtr <- data.frame(scale(Xi[tr, , drop = FALSE], mu, sdv),
        y = factor(yi[tr], levels = 0:6, ordered = TRUE)
      )
      fit <- suppressWarnings(MASS::polr(y ~ ., data = dtr, Hess = TRUE))
      pred[te] <- as.integer(as.character(
        predict(fit, data.frame(scale(Xi[te, , drop = FALSE], mu, sdv)), type = "class")
      ))
    }
    c(exact = mean(pred == yi), near_miss = mean(abs(pred - yi) <= 1))
  }
  res <- vapply(seq_len(1000), ord_once, numeric(2))
  ord_dist <- data.frame(
    iteration = seq_len(1000), exact = res["exact", ], near_miss = res["near_miss", ]
  )
  dir.create(dirname(ord_dist_cache), showWarnings = FALSE, recursive = TRUE)
  saveRDS(ord_dist, ord_dist_cache)
}

# 5.3  Histograms matching 03_human_performance's distribution plots: sky-blue
# bars with a dashed red mean line (red is kept for the mean so it cannot be
# confused with the bars).
#
# Every iteration scores the same 3052 held-out predictions, so an accuracy can
# only ever be an integer multiple of 1/3052. Bins that are not a whole number of
# those steps wide therefore capture 3 attainable values in one bar and 2 in the
# next, leaving a comb of empty gaps that is an artefact of the binning rather
# than of the distribution. Bin width is fixed to `m` whole steps and the edges
# are offset by half a step, so each bar covers exactly m attainable values.
n_pred <- nrow(feat)
dist_panel <- function(v, xlab, title, target_bins = 20) {
  step <- 1 / n_pred
  m <- max(1, round(diff(range(v)) / (target_bins * step)))
  ggplot(data.frame(v = v), aes(v)) +

# Held-out (grouped cross validation) predictors. The ordinal-regression
# predictors (ord_best, ord_tr) are defined in section 5 above.
thresh_cv <- function(x) {
  pred <- integer(length(y))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    med <- tapply(x[tr], y[tr], median)
    sc <- as.integer(names(med))
    o <- order(sc)
    med <- med[o]
    sc <- sc[o]
    cuts <- cummax((head(med, -1) + tail(med, -1)) / 2)
    pred[te] <- sc[findInterval(x[te], cuts) + 1]
  }
  pred
}
# Training (resubstitution) predictors, for the train-cross-validation gap
thresh_train <- function(x) {
  med <- tapply(x, y, median)
  sc <- as.integer(names(med))
  o <- order(sc)
  med <- med[o]
  sc <- sc[o]
  cuts <- cummax((head(med, -1) + tail(med, -1)) / 2)
  sc[findInterval(x, cuts) + 1]
}
knn_train_at <- function(k) { # self-inclusive; meaningful for k > 1
  mu <- colMeans(X)
  sdv <- apply(X, 2, sd)
  sdv[sdv == 0] <- 1
  Xs <- scale(X, mu, sdv)
  d <- outer(rowSums(Xs^2), rowSums(Xs^2), "+") - 2 * Xs %*% t(Xs)
  ord <- t(apply(d, 1, order))
  apply(ord[, 1:k, drop = FALSE], 1, function(ix) {
    tb <- table(y[ix])
    as.integer(names(tb)[which.max(tb)])
  })
}

10. Importance against univariate separability

Gini and SHAP both rank features by how much a fitted model leans on them, which is not the same as how well a feature separates severity on its own. The univariate measure is the mean adjacent-class AUC from 10_segmentation_and_feature_extraction: for each neighbouring score pair (0-1, 1-2, and so on) the probability that a CDA from the higher score has the larger feature value, averaged over the six pairs, where 0.5 is no separation. Plotting one against the other shows whether the models are simply recovering the univariate ranking or exploiting something a single feature cannot see.

  • Both rankings track separability almost exactly, at Spearman 0.95 for Gini and 0.94 for SHAP, so neither model is finding much beyond what each feature already does on its own.
  • mean_green is the clearest exception, separating adjacent classes at AUC 0.63 yet drawing a mean absolute SHAP of only 0.07, because its signal is already carried by cda_green and log_gr, which it correlates with strongly.
  • cda_green_sd sits at AUC 0.49 with the lowest score on both measures, so the models agree with the univariate view that lesion mottling is uninformative.

# 10.1  Mean adjacent-class AUC per feature, recomputed here from the exported
# table so this analysis stays self-contained. Definition matches
# 10_segmentation_and_feature_extraction, and it is measured on the full
# unbalanced dataset, since separability is a property of the feature rather
# than of the balanced sample the models are fitted on.
auc_pair <- function(hi, lo) {
  r <- rank(c(hi, lo))
  (sum(r[seq_along(hi)]) - length(hi) * (length(hi) + 1) / 2) /
    (length(hi) * length(lo))
}
adjacent_auc <- function(x, score) {
  ok <- is.finite(x)
  x <- x[ok]
  score <- score[ok]
  cls <- sort(unique(score))
  mean(vapply(seq_len(length(cls) - 1), function(k) {
    auc_pair(x[score == cls[k + 1]], x[score == cls[k]])
  }, numeric(1)))
}

11. Interpretation and Discussion

  • The features place a CDA within one point of its score almost always but pin the exact score only about 60% of the time. Ordinal regression averages 60.8% exact across 1,000 balanced undersamples (95% interval 59.7 to 61.9) and 97.7% near-miss, so the ordering is recoverable while the exact class is not.
  • A linear model on an ordered scale is enough, and the margin is real. Ordinal regression beats the random forest (56.5%) and k-NN (55.6%) with only twelve coefficients and six cut-points, and every one of the 1,000 undersamples clears both, so there is little non-linear structure left for a tree ensemble to find.
  • Single-undersample figures should be read with care. The seed-42 draw reports 61.5% exact, the 91st percentile of the resampled distribution, so any headline resting on one balanced sample can be a point optimistic.
  • Regularising the forest costs almost nothing. A fully grown forest hits 92.4% training accuracy against 57.0% held-out, and capping it at 128 leaf nodes gives up 0.8 points of held-out accuracy to close a 35-point gap.
  • Gini importance and SHAP agree on what matters. CDA greenness and the log green-to-red ratio lead both rankings, while the two within-CDA texture features contribute a mean absolute SHAP of 0.01, so how mottled a lesion is matters far less than how green and bright it is.
  • Grouping folds by leaf changes less than expected. It costs the fully grown forest 1.9 points and the regularised forest 0.9, and leaves ordinal regression unchanged at 61.5% against 60.9% ungrouped, so the headline result was never resting on leaked leaf identity.
  • Low scores remain hard. Every interior class sits near 55% exact against 79.8% at score 0, so mild cell death is genuinely close to healthy tissue and to its neighbours, which is why a learned model is needed for the fine-grained scores.
