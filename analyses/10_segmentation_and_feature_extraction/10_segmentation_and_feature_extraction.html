Segmenting cell death area from leaf background

Date: 13/7/2026

GOHREP

Goal:

Test whether the cell death area (CDA) of a leaf can be separated from the healthy leaf background universally — with one method and no per-image manual threshold tuning — using the distribution of pixel values.

Hypothesis:

An earlier attempt (PhD_DL_Models/analyses/0009_Non_DL_Green_Channel_Analysis) watershedded on image brightness/grayscale and found the threshold had to be retuned per image. The reason is colour: under this UV-fluorescence imaging the healthy leaf is red (high R, low G) and cell death is yellow-green (G ≈ or > R), and red leaf and green CDA have similar brightness. Segmenting on a greenness channel (G − R) instead should separate CDA from leaf with a threshold that Otsu can set automatically per image, because the two tissues form distinct modes in greenness even when they do not in brightness.

Rationale:

Otsu’s method finds the threshold that best splits a bimodal distribution. If CDA and leaf are two modes in greenness, Otsu adapts to each image with no manual input. Where there is no CDA (median-0 leaves), there is only one mode, so segmentation is only meaningful once an image is known to be non-zero — hence 0 and non-0 are treated separately here.

# 1.3
load_img <- function(path) {
  img <- readTIFF(path, info = FALSE)
  if (length(dim(img)) == 2) img <- array(img, dim = c(dim(img), 3))
  img[, , 1:3, drop = FALSE]
}

# Leaf mask: non-black pixels (mean RGB >= 0.15), dropping the near-black
# background and holes. Analysis 09_image_entropy (§5.5) uses a comparable
# non-dark threshold on peak brightness.
leaf_mask <- function(img) (img[, , 1] + img[, , 2] + img[, , 3]) / 3 >= 0.15

# Greenness channel: green minus red. Healthy (red) leaf is strongly negative;
# yellow-green CDA is near zero or positive.
greenness <- function(img) img[, , 2] - img[, , 1]

# Otsu threshold on a value vector, plus the "separability" = between-class
# variance at the threshold / total variance (a 2-class eta^2 in [0,1]). High
# separability => the values are well split into two modes (bimodal).
otsu_sep <- function(x, nbins = 64) {
  rng <- range(x)
  if (diff(rng) < 1e-6) {
    return(c(thr = rng[1], sep = 0, frac_hi = 0))
  }
  br <- seq(rng[1], rng[2], length.out = nbins + 1)
  mids <- (br[-1] + br[-length(br)]) / 2
  h <- tabulate(cut(x, br, include.lowest = TRUE), nbins)
  p <- h / sum(h)
  mu <- sum(p * mids)
  tot <- sum(p * (mids - mu)^2)
  w1 <- cumsum(p)
  m1 <- cumsum(p * mids)
  bcv <- (mu * w1 - m1)^2 / (w1 * (1 - w1) + 1e-12)
  k <- which.max(bcv)
  c(thr = br[k + 1], sep = max(bcv) / (tot + 1e-12), frac_hi = mean(x > br[k + 1]))
}

# Full spatial segmentation of one image: Otsu on the (blurred) greenness within
# the leaf, followed by morphological cleanup.
segment_cda <- function(img, sigma = 2) {
  leaf <- leaf_mask(img)
  g <- greenness(img)
  gs <- (g - min(g)) / (max(g) - min(g) + 1e-9) # rescale to 0-1 for EBImage
  gb <- EBImage::gblur(gs, sigma = sigma)
  thr <- EBImage::otsu(matrix(gb[leaf]), range = c(0, 1))
  mask <- leaf & (gb > thr)
  # Clean up with a median filter, whose radius scales with image size so the
  # smoothing is constant across crop resolutions: base 5 px at the 264-px median
  # crop, applied at radius 2*base. A median filter removes thin protrusions
  # (veins, spurs) far more effectively than a morphological opening of the same
  # scale while barely shrinking the bulk; see the cleanup comparison in section
  # 3.3 for the circularity/area justification of this choice.
  b <- max(1, round(5 * mean(dim(img)[1:2]) / 264))
  mask <- EBImage::fillHull(EBImage::medianFilter(mask, 2 * b))
  # The median filter and fillHull ignore the leaf boundary, so they can bridge
  # across background notches and pull off-leaf (near-black) pixels into the mask.
  # Re-apply the leaf mask so the CDA can never extend onto the background.
  mask <- mask & leaf
  # Keep only the largest connected component, dropping small floating islands.
  lab <- EBImage::bwlabel(mask)
  if (max(lab) > 1) mask <- lab == which.max(tabulate(lab[lab > 0]))
  # Re-applying the leaf mask above punches holes back into the CDA wherever the
  # leaf is dark inside the lesion (veins, specks below the 0.15 brightness cut).
  # Fill those enclosed holes so the CDA is a single solid region with no interior
  # dots in its outline. fillHull only fills fully-enclosed holes, so it cannot
  # re-extend the mask back onto the background.
  mask <- EBImage::fillHull(mask)
  list(leaf = leaf, greenness = gb, mask = mask, cda_frac = mean(mask))
}

# Render a single-channel raster (e.g. the greenness map) as RGB, recolouring
# pixels outside `keep` (e.g. off-leaf background) a flat colour. Used so the
# Otsu-excluded background reads visually distinct from the leaf pixels that
# actually feed the threshold, rather than looking like more greenness data.
recolour_outside <- function(chan, keep, colour = c(0.12, 0.56, 1)) {
  out <- array(chan, dim = c(dim(chan), 3))
  for (k in 1:3) {
    ch <- out[, , k]
    ch[!keep] <- colour[k]
    out[, , k] <- ch
  }
  out
}

# Draw a coloured outline of a mask onto an image (a boundary band of the given
# half-width), leaving the interior visible - clearer than a filled overlay.
outline <- function(img, mask, colour = c(0.12, 0.56, 1), width = 2) {
  br <- EBImage::makeBrush(2 * width + 1, "disc")
  edge <- EBImage::dilate(mask, br) & !EBImage::erode(mask, br)
  out <- img
  for (k in 1:3) {
    ch <- out[, , k]
    ch[edge] <- colour[k]
    out[, , k] <- ch
  }
  out
}

# Shannon entropy of pixel values in [0, 1], matching 09_image_entropy's
# shannon_entropy(): quantise to 8-bit intensities and take H = -sum(p*log2 p).
# region_entropy() applies it over the pixels of a mask, flattened across the
# three RGB channels, exactly as the whole-image version does.
shannon_entropy_vec <- function(v) {
  q <- as.integer(round(pmin(pmax(v, 0), 1) * 255))
  counts <- tabulate(q + 1L, nbins = 256L)
  p <- counts[counts > 0] / length(q)
  -sum(p * log2(p))
}
region_entropy <- function(img, mask) {
  if (!any(mask)) {
    return(NA_real_)
  }
  shannon_entropy_vec(c(img[, , 1][mask], img[, , 2][mask], img[, , 3][mask]))
}

3.2 Otsu vs background-only leaf masks

The spatial segmentation above isolates the cell-death area. A related but distinct question is which pixels count as leaf when estimating per-image lighting (used in the entropy analysis, 09_image_entropy, §5.5). Two thresholds on each CDA’s own brightness histogram are compared: the image-adaptive Otsu threshold, and a low fixed leaf cut (brightness >= 0.1) that removes only the near-black background and keeps all tissue. For one CDA per score, the original crop, the Otsu mask, and the background-only leaf mask are shown.

3.3 Choosing the morphological cleanup step

The raw Otsu mask is ragged: it carries thin vein spurs and a jagged boundary that the near-circular cell death phenotype does not have, so a smoothing step is applied before the region features are measured. Several scale-aware smoothers were compared to choose it, each scored by circularity (4πA/P², where 1 is a perfect circle) and area retained relative to the raw mask (1 = no shrinkage), on a sample of higher-severity crops where spurs are most visible.

A median filter at radius 2b was selected: it gives the roundest outlines (circularity 0.94) while shrinking the CDA the least (98.7% of the area retained). A morphological opening of comparable scale rounds less for more area loss, because it erodes the whole boundary rather than only the thin protrusions; a strong boundary blur over-rounds genuine lobes; and opening-by-reconstruction leaves spurs that are attached to the bulk untouched (its outline is identical to the raw mask), so it does not help here. All cleanup radii scale with image size (base b = round(5 · side / 264)), so the smoothing is constant across crop resolutions.

odd <- function(n) {
  n <- round(n)
  if (n %% 2 == 0) n <- n + 1
  max(3, n)
}
largest_cc <- function(mask) {
  lab <- EBImage::bwlabel(mask)
  if (max(lab) > 1) mask <- lab == which.max(tabulate(lab[lab > 0]))
  mask
}
# raw thresholded CDA mask, before any morphological cleanup
raw_cda_mask <- function(img, sigma = 2) {
  leaf <- leaf_mask(img)
  g <- greenness(img)
  gs <- (g - min(g)) / (max(g) - min(g) + 1e-9)
  gb <- EBImage::gblur(gs, sigma = sigma)
  thr <- EBImage::otsu(matrix(gb[leaf]), range = c(0, 1))
  leaf & (gb > thr)
}
# geodesic reconstruction by dilation of a marker under a mask
reconstruct <- function(marker, mask, brush) {
  prev <- marker
  for (i in 1:300) {
    cur <- EBImage::dilate(prev, brush) & mask
    if (all(cur == prev)) break
    prev <- cur
  }
  prev
}
cleanups <- list(
  "Raw" = function(m, b, d) largest_cc(EBImage::fillHull(m)),
  "Open x2" = function(m, b, d) {
    largest_cc(EBImage::fillHull(EBImage::opening(m, EBImage::makeBrush(odd(b * 2), "disc"))))
  },
  "Open x3" = function(m, b, d) {
    largest_cc(EBImage::fillHull(EBImage::opening(m, EBImage::makeBrush(odd(b * 3), "disc"))))
  },
  "Median r=b" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::medianFilter(m, b))),
  "Median r=2b" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::medianFilter(m, 2 * b))),
  "Blur sig=side/50" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::gblur(m * 1, sigma = d / 50) > 0.5)),
  "Blur sig=side/30" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::gblur(m * 1, sigma = d / 30) > 0.5)),
  "Reconstruction" = function(m, b, d) {
    br <- EBImage::makeBrush(odd(b), "disc")
    largest_cc(EBImage::fillHull(reconstruct(EBImage::erode(m, br), m, br)))
  }
)
circularity <- function(mask) {
  if (sum(mask) < 10) {
    return(NA_real_)
  }
  sh <- EBImage::computeFeatures.shape(EBImage::bwlabel(mask))
  if (is.null(sh) || nrow(sh) == 0 || sh[1, "s.perimeter"] <= 0) {
    return(NA_real_)
  }
  4 * pi * sh[1, "s.area"] / (sh[1, "s.perimeter"]^2)
}

4. Can the distribution alone detect whether a CDA is present?

Segmenting assumes a CDA exists. The natural universal test for “is there a CDA” is the bimodality (separability) of the leaf-greenness distribution. The following computes, for every image, the eleven region features summarised from the segmentation (§6.1), including the leaf-greenness separability. Computed once and cached.

Code 
# 5.1
cache_path <- here(
  "analyses", "10_segmentation_and_feature_extraction", "segmentation_cache",
  "cda_segmentation_metrics.rds"
)

if (file.exists(cache_path)) {
  seg <- readRDS(cache_path)
} else {
  scores <- list.dirs(data_dir, recursive = FALSE, full.names = FALSE)
  scores <- scores[grepl("^[0-9]+$", scores)]
  rows <- list()
  for (sc in scores) {
    files <- list.files(file.path(data_dir, sc), pattern = "\\.tif$", full.names = TRUE)
    m <- t(vapply(files, function(f) {
      # All region features are read off the SAME segmentation: the leaf mask,
      # the spatial CDA mask from segment_cda() (Otsu on blurred greenness ->
      # morphological cleanup -> largest connected component), and the healthy
      # leaf (leaf minus CDA). Nothing is re-thresholded per feature.
      img <- load_img(f)
      s <- segment_cda(img)
      leaf <- s$leaf # leaf region ((R+G+B)/3 >= 0.10)
      cda <- s$mask & leaf # segmented CDA (largest greenness component)
      healthy <- leaf & !cda # healthy leaf = leaf minus CDA
      gmat <- greenness(img) # greenness G - R over the whole image
      bmat <- (img[, , 1] + img[, , 2] + img[, , 3]) / 3 # brightness (mean RGB)
      R <- img[, , 1]
      G <- img[, , 2]
      nsd <- function(x) if (length(x) > 1) sd(x) else 0
      mn <- function(x) if (length(x)) mean(x) else 0

      gv_leaf <- gmat[leaf] # greenness over the whole leaf
      o <- otsu_sep(gv_leaf) # separability (bimodality) of leaf greenness
      n_green <- sum(G[leaf] >= R[leaf])
      n_red <- sum(R[leaf] > G[leaf]) # colour counts over leaf

      c(
        sep = unname(o["sep"]), # 4  leaf-greenness bimodality
        green_gap = if (any(cda) && any(healthy)) { # 3  CDA vs healthy-leaf greenness
          mean(gmat[cda]) - mean(gmat[healthy])
        } else {
          0

# Rank-based (Mann-Whitney) AUC: probability a random non-0 image scores higher
# than a random 0 image on the given feature.
auc <- function(feature, positive) {
  r <- rank(feature)
  n_pos <- sum(positive)
  n_neg <- sum(!positive)
  (sum(r[positive]) - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
}

# Separability is summarised as the mean adjacent-class AUC: for each pair of
# neighbouring scores (0-1, 1-2, ... 5-6), the probability that a CDA from the
# higher score has the larger feature value (ties count half), averaged over the
# six pairs. Adjacent pairs are the ones raters actually confuse (off-by-one
# disagreement), so this targets the separability that matters rather than being
# flattered by easily-separated far-apart scores. The general principle of
# averaging pairwise AUC over multiple classes follows Hand & Till (2001); 0.5
# marks no separability and 1 fully separated neighbours.
auc_pair <- function(hi, lo) {
  r <- rank(c(hi, lo))
  (sum(r[seq_along(hi)]) - length(hi) * (length(hi) + 1) / 2) /
    (length(hi) * length(lo))
}

  cls <- sort(unique(score))
  mean(vapply(seq_len(length(cls) - 1), function(k) {
    auc_pair(x[score == cls[k + 1]], x[score == cls[k]])
  }, numeric(1)))
}

6. Predicting score from the hand-crafted features

Can these hand-crafted features predict a CDA’s score? All modelling here uses a class-balanced dataset — every score downsampled to the smallest class — so the abundant score-0 class cannot dominate (the same balancing used in 07_visual_complexity and the AutoCDAScorer ensemble analysis). Because the classes are equal, a majority-class guess scores only 1/7 and exact accuracy equals balanced accuracy. Accuracy is reported as exact (predicted = true), near-miss (within ±1, as in 07_visual_complexity), and balanced (mean of the per-class exact accuracies).

The full pipeline, end to end, for one cropped CDA image:

  1. Load the raw RGB crop (no resizing — the features are scale-free).
  2. Leaf mask — keep pixels with mean brightness ≥ 0.1 (§1.3).
  3. Segment the CDA — Otsu threshold on the blurred leaf greenness (G − R), morphological cleanup, then keep the largest connected component (§3).
  4. Summarise the crop into 12 scalar features (§6.1).
  5. Predict the 0–6 score from those features (random forest, k-NN or ordinal regression). No per-image threshold tuning anywhere.

The twelve features — all per-image summaries of the raw crop, so they can be read directly off the importance (§6.7) and SHAP (§6.8) plots. “Greenness” means G − R (green minus red channel); the “CDA” is the segmented cell-death region (the largest connected greenness component after Otsu thresholding and morphological cleanup, §3); the “leaf” is all non-black pixels (§1.3); the “healthy leaf” is the leaf minus the CDA.

6.1 Assemble features, and a leakage-safe cross-validation

Each cropped CDA comes from a source leaf image (~29 crops per leaf). Crops from the same leaf share lighting, plant and tissue, so they are correlated; splitting them across training and held-out folds would leak information and inflate accuracy. All cross-validation here is therefore grouped by source leaf — whole leaves are assigned to folds, so no leaf ever appears in both the training and held-out folds. (Ungrouped image-level cross validation gives ~0.58 exact; grouping removes the leak and gives the honest ~0.55.) A shuffled-label check (§6.1) confirms the pipeline has no other leakage.

6.2 Choosing k for k-NN

k is swept over a range and chosen by grouped cross-validated exact accuracy (the supervised analogue of the k-selection in 07_visual_complexity). Held-out accuracy is essentially flat beyond k ≈ 5, so the precise value barely matters; it is taken as the cross validation maximum for definiteness. (Only held-out accuracy is shown — training-set accuracy is meaningless for k-NN, since at k = 1 each point is its own neighbour and scores 100% by construction.)

Code 
# 7.2.1
knn_cv <- function(ks) {
  P <- matrix(0L, nrow(X), length(ks), dimnames = list(NULL, paste0("k", ks)))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    mu <- colMeans(X[tr, ])
    sdv <- apply(X[tr, ], 2, sd)
    sdv[sdv == 0] <- 1
    Xtr <- scale(X[tr, , drop = FALSE], mu, sdv)
    Xte <- scale(X[te, , drop = FALSE], mu, sdv)
    d <- outer(rowSums(Xte^2), rowSums(Xtr^2), "+") - 2 * Xte %*% t(Xtr)
    ytr <- y[tr]
    ord <- t(apply(d, 1, order))
    for (j in seq_along(ks)) {
      P[te, j] <- apply(ord[, 1:ks[j], drop = FALSE], 1, function(ix) {
        tb <- table(ytr[ix])
        as.integer(names(tb)[which.max(tb)])
      })
    }
  }
  P
}

6.3 Random forest: regularising to control overfitting

A fully-grown random forest memorises the training set — its training accuracy is ~0.91 against ~0.55 held-out, a ~36-point gap — so by the rule of discarding any model whose train–cross-validation gap exceeds 15%, it must be regularised. The forest is fixed at 200 trees (accuracy plateaus well before that, and more trees never hurt a random forest) and the tree size is capped with maxnodes, increasing it until the train–cross-validation gap reaches 15%; the largest held-out accuracy within that bound is chosen. Training accuracy is fit and scored on all the data (resubstitution); held-out is the grouped 5-fold cross validation.

Code

6.4 Ordinal regression

Proportional-odds ordinal logistic regression models the ordered 0–6 scale directly: a single linear predictor is fit to the 12 features, and six ordered cut-points split that predictor into the seven score classes, so the model respects the ordering of the scale rather than treating the classes as unrelated labels. It has no hyperparameter to tune, so unlike k-NN (§6.2) and the random forest (§6.3) there is no sweep — just the fit below, scored under the same source-grouped cross validation. With only twelve coefficients plus the cut-points it has little capacity to memorise the training set, so its training and held-out accuracy are almost identical.

Code 
# 7.4.0  Ordinal logistic regression (proportional odds, MASS::polr), scored under
# the same source-grouped cross validation. Features are standardised with
# training-fold statistics inside each fold, so nothing leaks into the scaling.
ord_cv <- function() {
  pred <- integer(length(y))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    mu <- colMeans(X[tr, ])
    sdv <- apply(X[tr, ], 2, sd)
    sdv[sdv == 0] <- 1
    dtr <- data.frame(scale(X[tr, , drop = FALSE], mu, sdv),
      y = factor(y[tr], levels = 0:6, ordered = TRUE)
    )
    dte <- data.frame(scale(X[te, , drop = FALSE], mu, sdv))
    fit <- suppressWarnings(MASS::polr(y ~ ., data = dtr, Hess = TRUE))
    pred[te] <- as.integer(as.character(predict(fit, dte, type = "class")))
  }
  pred
}
ord_train <- function() {
  mu <- colMeans(X)
  sdv <- apply(X, 2, sd)
  sdv[sdv == 0] <- 1
  d <- data.frame(scale(X, mu, sdv), y = factor(y, levels = 0:6, ordered = TRUE))
  fit <- suppressWarnings(MASS::polr(y ~ ., data = d, Hess = TRUE))
  as.integer(as.character(predict(fit, data.frame(scale(X, mu, sdv)), type = "class")))
}

# Held-out (grouped cross validation) predictors. The ordinal-regression
# predictors (ord_best, ord_tr) are defined in section 6.4 above.
thresh_cv <- function(x) {
  pred <- integer(length(y))
  for (f in 1:K) {
    tr <- fold != f
    te <- fold == f
    med <- tapply(x[tr], y[tr], median)
    sc <- as.integer(names(med))
    o <- order(sc)
    med <- med[o]
    sc <- sc[o]
    cuts <- cummax((head(med, -1) + tail(med, -1)) / 2)
    pred[te] <- sc[findInterval(x[te], cuts) + 1]
  }
  pred
}
# Training (resubstitution) predictors, for the train-cross-validation gap

  med <- tapply(x, y, median)

  med <- med[o]
  sc <- sc[o]

}

8. Interpretation and Discussion

  • Greenness solves the universal-threshold problem. Switching the segmentation channel from brightness to greenness (G − R) makes CDA and leaf distinct modes, so Otsu sets the threshold automatically per image with no manual tuning (§2–§3). This is the fix for the failure in 0009_Non_DL_Green_Channel_Analysis, where brightness watershedding needed a different threshold for every image.
  • Presence detection works, but segment conditionally. The bimodality (separability) of the leaf-greenness distribution classifies 0 vs non-0 well on its own (AUC ≈ 0.94, §4.2), so the distribution does detect whether a CDA is present — confirming this is the easy part of the problem. But if the spatial Otsu segmentation is run unconditionally it still outlines a spurious region on a median-0 leaf (§3), so segmentation should be gated on the non-0 decision, as hypothesised.
  • The features predict score to ±1 reliably, but the exact score only about half the time (§6). All modelling is on the class-balanced data (436/class), so there is no score-0 free ride and exact = balanced accuracy, and all accuracy is measured with source-grouped 5-fold cross validation (a leaf’s crops are never split across folds; an image-level split leaks ~2–3 points, §6.1). A shuffled-label check collapses to chance, confirming no other leakage. The best model is a linear ordinal regression at 61% held-out exact and 98% near-miss, with a train–cross-validation gap of essentially zero; a regularised random forest (tree size capped so the train–cross-validation gap stays under 15%, §6.3) and a k-NN (k = 27, chosen by cross validation) trail a few points behind. A single-feature threshold rule reaches 11%. The confusion matrix is a tight band-diagonal (errors almost entirely between adjacent scores; score 1 mostly confused with 0 and 2), so the features locate a CDA to within ±1 of its score almost always but cannot pin the exact neighbouring severity. An unregularised forest reaches ~91% training accuracy but the same ~55% held-out — pure memorisation (a ~36-point gap), so it is discarded; regularising costs almost nothing in held-out accuracy. For reference (not a like-for-like comparison), the project’s deep-learning models reach ~70% training and 60–67% held-out test — a small gap and higher test accuracy than these hand-crafted features.
  • Gini importance and SHAP agree on what matters (§6.7–6.8). CDA greenness, the green/red ratio, greenness bimodality and CDA brightness drive the predictions. The SHAP beeswarm shows high values of these features push the prediction toward higher scores, consistently across images rather than as narrow high- or low-severity specialists; the dependence plots show mostly monotonic (area saturating) effects, and the within-CDA texture features (cda_green_sd, cda_bright_sd) sit near zero — how mottled a lesion is matters far less than how large, green and bright it is.
  • Low scores remain hard. At scores 1–2 the CDA is barely greener than the leaf, so the modes overlap and the segmentation features overlap the neighbouring classes (§5, §6). This is the same faint-signal regime that limits every hand-crafted feature in 09_image_entropy — mild cell death is genuinely close to healthy tissue in these images, which is why a learned model is needed to resolve the fine-grained scores.
