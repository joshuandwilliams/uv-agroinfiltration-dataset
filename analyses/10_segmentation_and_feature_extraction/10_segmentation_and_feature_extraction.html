Segmenting cell death area from leaf background

Date: 13/7/2026

GOHREP

Goal:

Test whether the cell death area (CDA) of a leaf can be separated from the healthy leaf background universally, with one method and no per-image manual threshold tuning, using the distribution of pixel values.

Hypothesis:

An earlier attempt (PhD_DL_Models/analyses/0009_Non_DL_Green_Channel_Analysis) watershedded on image brightness and found the threshold had to be retuned per image. The reason is colour. Under this UV-fluorescence imaging the healthy leaf is red (high R, low G) and cell death is yellow-green (G at or above R), and red leaf and green CDA have similar brightness. Segmenting on a greenness channel (G - R) instead should separate CDA from leaf with a threshold that Otsu can set automatically per image, because the two tissues form distinct modes in greenness even when they do not in brightness.

Rationale:

Otsu’s method finds the threshold that best splits a bimodal distribution. If CDA and leaf are two modes in greenness, Otsu adapts to each image with no manual input. Where there is no CDA (median-0 leaves) there is only one mode, so segmentation is only meaningful once an image is known to be non-zero. 0 and non-0 are therefore treated separately here.

# 1.3
load_img <- function(path) {
  img <- readTIFF(path, info = FALSE)
  if (length(dim(img)) == 2) img <- array(img, dim = c(dim(img), 3))
  img[, , 1:3, drop = FALSE]
}

# Leaf mask: non-black pixels (mean RGB >= 0.15), dropping the near-black
# background and holes. 09_image_entropy uses a comparable non-dark threshold
# on peak brightness.
leaf_mask <- function(img) (img[, , 1] + img[, , 2] + img[, , 3]) / 3 >= 0.15

# Greenness channel: green minus red. Healthy (red) leaf is strongly negative;
# yellow-green CDA is near zero or positive.
greenness <- function(img) img[, , 2] - img[, , 1]

# Otsu threshold on a value vector, plus the "separability" = between-class
# variance at the threshold / total variance (a 2-class eta^2 in [0,1]). High
# separability => the values are well split into two modes (bimodal).
otsu_sep <- function(x, nbins = 64) {
  rng <- range(x)
  if (diff(rng) < 1e-6) {
    return(c(thr = rng[1], sep = 0, frac_hi = 0))
  }
  br <- seq(rng[1], rng[2], length.out = nbins + 1)
  mids <- (br[-1] + br[-length(br)]) / 2
  h <- tabulate(cut(x, br, include.lowest = TRUE), nbins)
  p <- h / sum(h)
  mu <- sum(p * mids)
  tot <- sum(p * (mids - mu)^2)
  w1 <- cumsum(p)
  m1 <- cumsum(p * mids)
  bcv <- (mu * w1 - m1)^2 / (w1 * (1 - w1) + 1e-12)
  k <- which.max(bcv)
  c(thr = br[k + 1], sep = max(bcv) / (tot + 1e-12), frac_hi = mean(x > br[k + 1]))
}

# Full spatial segmentation of one image: Otsu on the (blurred) greenness within
# the leaf, followed by morphological cleanup.
segment_cda <- function(img, sigma = 2) {
  leaf <- leaf_mask(img)
  g <- greenness(img)
  gs <- (g - min(g)) / (max(g) - min(g) + 1e-9) # rescale to 0-1 for EBImage
  gb <- EBImage::gblur(gs, sigma = sigma)
  thr <- EBImage::otsu(matrix(gb[leaf]), range = c(0, 1))
  mask <- leaf & (gb > thr)
  # Clean up with a median filter, whose radius scales with image size so the
  # smoothing is constant across crop resolutions: base 5 px at the 264-px median
  # crop, applied at radius 2*base. A median filter removes thin protrusions
  # (veins, spurs) far more effectively than a morphological opening of the same
  # scale while barely shrinking the bulk, at 0.95 circularity for 98.6% of the
  # area retained (see the cleanup comparison below).
  b <- max(1, round(5 * mean(dim(img)[1:2]) / 264))
  mask <- EBImage::fillHull(EBImage::medianFilter(mask, 2 * b))
  # The median filter and fillHull ignore the leaf boundary, so they can bridge
  # across background notches and pull off-leaf (near-black) pixels into the mask.
  # Re-apply the leaf mask so the CDA can never extend onto the background.
  mask <- mask & leaf
  # Keep only the largest connected component, dropping small floating islands.
  lab <- EBImage::bwlabel(mask)
  if (max(lab) > 1) mask <- lab == which.max(tabulate(lab[lab > 0]))
  # Re-applying the leaf mask above punches holes back into the CDA wherever the
  # leaf is dark inside the lesion (veins, specks below the 0.15 brightness cut).
  # Fill those enclosed holes so the CDA is a single solid region with no interior
  # dots in its outline. fillHull only fills fully-enclosed holes, so it cannot
  # re-extend the mask back onto the background.
  mask <- EBImage::fillHull(mask)
  list(leaf = leaf, greenness = gb, mask = mask, cda_frac = mean(mask))
}

# Render a single-channel raster (e.g. the greenness map) as RGB, recolouring
# pixels outside `keep` (e.g. off-leaf background) a flat colour. Used so the
# Otsu-excluded background reads visually distinct from the leaf pixels that
# actually feed the threshold, rather than looking like more greenness data.
recolour_outside <- function(chan, keep, colour = c(0.12, 0.56, 1)) {
  out <- array(chan, dim = c(dim(chan), 3))
  for (k in 1:3) {
    ch <- out[, , k]
    ch[!keep] <- colour[k]
    out[, , k] <- ch
  }
  out
}

# Overlay a mask on an image by turning masked pixels yellow-magenta.
overlay <- function(img, mask, colour = c(1, 0, 1)) {
  out <- img
  for (k in 1:3) {
    ch <- out[, , k]
    ch[mask] <- colour[k]
    out[, , k] <- ch
  }
  out
}

# Draw a coloured outline of a mask onto an image (a boundary band of the given
# half-width), leaving the interior visible - clearer than a filled overlay.
outline <- function(img, mask, colour = c(0.12, 0.56, 1), width = 2) {
  br <- EBImage::makeBrush(2 * width + 1, "disc")
  edge <- EBImage::dilate(mask, br) & !EBImage::erode(mask, br)
  out <- img
  for (k in 1:3) {
    ch <- out[, , k]
    ch[edge] <- colour[k]
    out[, , k] <- ch
  }
  out
}

# Shannon entropy of pixel values in [0, 1], matching 09_image_entropy's
# shannon_entropy(): quantise to 8-bit intensities and take H = -sum(p*log2 p).
# region_entropy() applies it over the pixels of a mask, flattened across the
# three RGB channels, exactly as the whole-image version does.
shannon_entropy_vec <- function(v) {
  q <- as.integer(round(pmin(pmax(v, 0), 1) * 255))
  counts <- tabulate(q + 1L, nbins = 256L)
  p <- counts[counts > 0] / length(q)
  -sum(p * log2(p))
}
region_entropy <- function(img, mask) {
  if (!any(mask)) {
    return(NA_real_)
  }
  shannon_entropy_vec(c(img[, , 1][mask], img[, , 2][mask], img[, , 3][mask]))
}

3.2 Otsu vs background-only leaf masks

Which pixels count as leaf when estimating per-image lighting is a separate question from segmenting the lesion. The image-adaptive Otsu threshold is compared against a low fixed cut (brightness at or above 0.10) that removes only the near-black background.

leaf_mask_examples <- lapply(c(0, 2, 4, 6), function(sc) {
  files <- list.files(file.path(data_dir, sc), pattern = "\\.tif$", full.names = TRUE)
  f <- sample(files, 1)
  img <- readTIFF(f, info = FALSE)

    sc = sc, img = img, otsu = otsu_mask, leaf = leaf_mask,
    otsu_frac = mean(otsu_mask), leaf_frac = mean(leaf_mask)

})

3.3 Choosing the morphological cleanup step

  • A median filter at radius 2b gives the roundest outline at circularity 0.95 while retaining 98.6% of the raw mask area, so it strips vein spurs without eroding the lesion.
  • The raw mask sits at circularity 0.68 and opening-by-reconstruction leaves it there unchanged, so reconstruction is no use against spurs attached to the bulk of the mask.

odd <- function(n) {
  n <- round(n)
  if (n %% 2 == 0) n <- n + 1
  max(3, n)
}
largest_cc <- function(mask) {
  lab <- EBImage::bwlabel(mask)
  if (max(lab) > 1) mask <- lab == which.max(tabulate(lab[lab > 0]))
  mask
}
# raw thresholded CDA mask, before any morphological cleanup
raw_cda_mask <- function(img, sigma = 2) {
  leaf <- leaf_mask(img)
  g <- greenness(img)
  gs <- (g - min(g)) / (max(g) - min(g) + 1e-9)
  gb <- EBImage::gblur(gs, sigma = sigma)
  thr <- EBImage::otsu(matrix(gb[leaf]), range = c(0, 1))
  leaf & (gb > thr)
}
# geodesic reconstruction by dilation of a marker under a mask
reconstruct <- function(marker, mask, brush) {
  prev <- marker
  for (i in 1:300) {
    cur <- EBImage::dilate(prev, brush) & mask
    if (all(cur == prev)) break
    prev <- cur
  }
  prev
}
cleanups <- list(
  "Raw" = function(m, b, d) largest_cc(EBImage::fillHull(m)),
  "Open x2" = function(m, b, d) {
    largest_cc(EBImage::fillHull(EBImage::opening(m, EBImage::makeBrush(odd(b * 2), "disc"))))
  },
  "Open x3" = function(m, b, d) {
    largest_cc(EBImage::fillHull(EBImage::opening(m, EBImage::makeBrush(odd(b * 3), "disc"))))
  },
  "Median r=b" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::medianFilter(m, b))),
  "Median r=2b" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::medianFilter(m, 2 * b))),
  "Blur sig=side/50" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::gblur(m * 1, sigma = d / 50) > 0.5)),
  "Blur sig=side/30" = function(m, b, d) largest_cc(EBImage::fillHull(EBImage::gblur(m * 1, sigma = d / 30) > 0.5)),
  "Reconstruction" = function(m, b, d) {
    br <- EBImage::makeBrush(odd(b), "disc")
    largest_cc(EBImage::fillHull(reconstruct(EBImage::erode(m, br), m, br)))
  }
)
circularity <- function(mask) {
  if (sum(mask) < 10) {
    return(NA_real_)
  }
  sh <- EBImage::computeFeatures.shape(EBImage::bwlabel(mask))
  if (is.null(sh) || nrow(sh) == 0 || sh[1, "s.perimeter"] <= 0) {
    return(NA_real_)
  }
  4 * pi * sh[1, "s.area"] / (sh[1, "s.perimeter"]^2)
}

4. Can the distribution alone detect whether a CDA is present?

Segmenting assumes a CDA exists. The natural universal test for whether a lesion is present is the bimodality of the leaf-greenness distribution, computed below for every image alongside the other region features.

Code 
# 5.1
cache_path <- here(
  "analyses", "10_segmentation_and_feature_extraction", "segmentation_cache",
  "cda_segmentation_metrics.rds"
)

if (file.exists(cache_path)) {
  seg <- readRDS(cache_path)
} else {
  scores <- list.dirs(data_dir, recursive = FALSE, full.names = FALSE)
  scores <- scores[grepl("^[0-9]+$", scores)]
  rows <- list()
  for (sc in scores) {
    files <- list.files(file.path(data_dir, sc), pattern = "\\.tif$", full.names = TRUE)
    m <- t(vapply(files, function(f) {
      # All region features are read off the SAME segmentation: the leaf mask,
      # the spatial CDA mask from segment_cda() (Otsu on blurred greenness ->
      # morphological cleanup -> largest connected component), and the healthy
      # leaf (leaf minus CDA). Nothing is re-thresholded per feature.
      img <- load_img(f)
      s <- segment_cda(img)
      leaf <- s$leaf # leaf region ((R+G+B)/3 >= 0.15)
      cda <- s$mask & leaf # segmented CDA (largest greenness component)
      healthy <- leaf & !cda # healthy leaf = leaf minus CDA
      gmat <- greenness(img) # greenness G - R over the whole image
      bmat <- (img[, , 1] + img[, , 2] + img[, , 3]) / 3 # brightness (mean RGB)
      R <- img[, , 1]
      G <- img[, , 2]
      nsd <- function(x) if (length(x) > 1) sd(x) else 0
      mn <- function(x) if (length(x)) mean(x) else 0

      gv_leaf <- gmat[leaf] # greenness over the whole leaf
      o <- otsu_sep(gv_leaf) # separability (bimodality) of leaf greenness
      n_green <- sum(G[leaf] >= R[leaf])
      n_red <- sum(R[leaf] > G[leaf]) # colour counts over leaf

      c(
        sep = unname(o["sep"]), # 4  leaf-greenness bimodality
        green_gap = if (any(cda) && any(healthy)) { # 3  CDA vs healthy-leaf greenness
          mean(gmat[cda]) - mean(gmat[healthy])
        } else {
          0
        },
        cda_green = mn(gmat[cda]), # 2  CDA greenness

        cda_bright_sd = nsd(bmat[cda]) * 255, # 8  within-CDA brightness spread

        mean_green = mn(G[leaf]) * 255, # 10 mean green over leaf
        log_gr = log((n_green + 1) / (n_red + 1)), # 9  log green:red count over leaf
        leaf_bright = mn(bmat[leaf]) * 255, # 11 leaf brightness
        ent_gap = if (any(cda) && any(healthy)) { # 12 CDA minus healthy-leaf Shannon entropy
          region_entropy(img, cda) - region_entropy(img, healthy)
        } else {
          0
        }
      )
    }, numeric(12)))

      image_id = tools::file_path_sans_ext(basename(files)),
      score = as.integer(sc), m, row.names = NULL
    )
    message(sprintf("score %s done (%d)", sc, length(files)))
  }
  seg <- dplyr::bind_rows(rows)
  saveRDS(seg, cache_path)

# Rank-based (Mann-Whitney) AUC: probability a random non-0 image scores higher
# than a random 0 image on the given feature.
auc <- function(feature, positive) {
  r <- rank(feature)
  n_pos <- sum(positive)
  n_neg <- sum(!positive)
  (sum(r[positive]) - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
}

4.1 The twelve features, and the exported feature table

The full pipeline, end to end, for one cropped CDA image:

  1. Load the raw RGB crop. No resizing, since every feature is a mean, a spread or a ratio and so does not depend on the crop’s pixel dimensions.
  2. Leaf mask. Keep pixels whose mean RGB is at least 0.15, which drops the near-black off-leaf background.
  3. Segment the CDA. Rescale greenness (G - R) to 0-1, Gaussian blur at sigma 2, take the Otsu threshold over the leaf pixels only, smooth the mask with a median filter at radius 2b (b = round(5 x side / 264), so smoothing is constant across crop resolutions), re-apply the leaf mask, keep the largest connected component, and fill its enclosed holes.
  4. Summarise the crop. Eleven scalar features are measured here, and Shannon entropy is joined from 09_image_entropy to make twelve.

No per-image threshold tuning anywhere. “Greenness” means G - R (green minus red channel). The “CDA” is the segmented region from step 3, the “leaf” is every pixel kept by step 2, and the “healthy leaf” is the leaf minus the CDA.

Segmentation features, measured in this analysis:

Variable Feature What it measures With severity
ent_gap CDA-leaf entropy difference Shannon entropy (bits) of the segmented CDA minus that of the healthy leaf rises
cda_green CDA greenness mean greenness (G − R) inside the segmented CDA rises
green_gap CDA–leaf contrast CDA greenness minus healthy-leaf (leaf minus CDA) greenness rises
sep greenness bimodality Otsu between-class ÷ total variance of leaf greenness (0–1): how cleanly the leaf splits into CDA + healthy rises (also detects presence)
cda_bright CDA brightness mean brightness (mean of R,G,B, 0–255) inside the CDA rises
leaf_green_sd whole-leaf greenness spread SD of greenness over all leaf pixels (0–255) rises
cda_green_sd within-CDA greenness spread SD of greenness among CDA pixels: how mottled the lesion’s colour is ~flat
cda_bright_sd within-CDA brightness spread SD of brightness among CDA pixels ~flat

Colour, brightness and entropy features, taken from 09_image_entropy:

Variable Feature What it measures With severity
mean_green mean green mean green-channel intensity over leaf pixels (0–255) rises
log_gr log green/red ratio log of the green-pixel to red-pixel count ratio over leaf pixels rises
leaf_bright leaf brightness mean brightness over non-black leaf pixels (0–255) rises
entropy_raw Shannon entropy information content of the raw crop (bits) weakly rises

The table is the input to 10b_score_prediction.qmd and 11_project_feature_differences.

# 6.2b  Per-feature class separability.
# Shown standalone here and reused as panel C of the features-by-score figure.
#
# Separability is summarised as the mean adjacent-class AUC: for each pair of
# neighbouring scores (0-1, 1-2, ... 5-6), the probability that a CDA from the
# higher score has the larger feature value (ties count half), averaged over the
# six pairs. Adjacent pairs are the ones raters actually confuse (off-by-one
# disagreement), so this targets the separability that matters rather than being
# flattered by easily-separated far-apart scores. The general principle of
# averaging pairwise AUC over multiple classes follows Hand & Till (2001); 0.5
# marks no separability and 1 fully separated neighbours.
auc_pair <- function(hi, lo) {
  r <- rank(c(hi, lo))
  (sum(r[seq_along(hi)]) - length(hi) * (length(hi) + 1) / 2) /
    (length(hi) * length(lo))
}
adjacent_auc <- function(x, score) {
  ok <- is.finite(x)
  x <- x[ok]
  score <- score[ok]
  cls <- sort(unique(score))
  mean(vapply(seq_len(length(cls) - 1), function(k) {
    auc_pair(x[score == cls[k + 1]], x[score == cls[k]])
  }, numeric(1)))
}

  auc = vapply(feat_order, function(f) adjacent_auc(feat6[[f]], feat6$score), numeric(1))

# Dendrogram line segments straight from the hclust object (ggdendro is not

dendro_segments <- function(hc) {
  n <- length(hc$order)
  xpos <- match(seq_len(n), hc$order) # leaf i sits at this x position
  cx <- cy <- numeric(nrow(hc$merge))
  node <- function(i) if (i < 0) list(x = xpos[-i], y = 0) else list(x = cx[i], y = cy[i])
  segs <- vector("list", nrow(hc$merge))
  for (k in seq_len(nrow(hc$merge))) {
    a <- node(hc$merge[k, 1])
    b <- node(hc$merge[k, 2])
    h <- hc$height[k]
    segs[[k]] <- data.frame(
      x = c(a$x, b$x, a$x), xend = c(a$x, b$x, b$x),
      y = c(a$y, b$y, h), yend = c(h, h, h)
    )
    cx[k] <- (a$x + b$x) / 2
    cy[k] <- h
  }
  do.call(rbind, segs)
}

  Xm <- pmin(pmax(Xm, 0), 1)
  po <- prcomp(Xo, center = TRUE, rank. = 3)
  pm <- prcomp(Xm, center = TRUE, rank. = 3)
  eta_by_pc <- function(x) {
    sapply(1:2, function(j) {
      v <- x[, j]
      gr <- mean(v)
      sum(tapply(v, y_pca, function(z) length(z) * (mean(z) - gr)^2)) / sum((v - gr)^2)
    })
  }
  pca_res <- list(
    score = y_pca,
    orig = po$x[, 1:2], masked = pm$x[, 1:2],
    orig_var = summary(po)$importance[2, 1:2], masked_var = summary(pm)$importance[2, 1:2],
    orig_eta = eta_by_pc(po$x), masked_eta = eta_by_pc(pm$x)
  )
  saveRDS(pca_res, pca_cache)
}

7. Interpretation and Discussion

  • Greenness solves the universal-threshold problem. Otsu’s brightness cut moves from 66 to 137 of 255 between two crops while its greenness cut holds at -0.16 to -0.15, so changing channel is what removes the per-image tuning that defeated the earlier brightness watershed.
  • Presence detection works, so segmentation should be conditional. Leaf-greenness bimodality separates 0 from non-0 at AUC 0.944, yet the spatial segmentation still carves 49% of a score-0 leaf into a spurious lesion, so it should run only after the non-zero decision.
  • The features track severity without separating neighbouring scores. Three features reach rho = 0.84 against score, but the best adjacent-class AUC is 0.68, so the ordering is recoverable while the exact class is not.
  • The feature set is redundant. Near-duplicate pairs reach rho = 0.97, so the twelve columns carry far fewer than twelve independent measurements.
  • What the features can predict is answered in 10b_score_prediction.qmd, where they place a CDA within one point of its score almost always but pin the exact score about 60% of the time.
  • Low scores remain hard. Median CDA greenness at scores 1-2 (-0.13 and -0.08) is barely above the score-0 value of -0.19, so mild cell death is genuinely close to healthy tissue in these images.
