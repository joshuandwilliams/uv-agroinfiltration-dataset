Scoring Order Effects

Date: 08/7/2026

GOHREP

Goal:

Test whether scoring shows order-dependent effects — image-blocking (shared visual context from consecutive same-image CDAs), genuine sequential drift over a session, or relative anchoring to the immediately-preceding CDA — as opposed to each CDA being scored independently of its neighbours.

Hypothesis:

Any residual autocorrelation in the original (image-ordered) scoring is explained by shared image context, not by rater fatigue/drift or by anchoring to the previous CDA’s score. If so, it should vanish once CDAs cross an image boundary, and should also be absent from the rescore session (randomised order).

Rationale:

This was previously split across two analyses (05_inter_rater_agreement/05_inter_rater_agreement.qmd and 06_intra_rater_reliability/intra_rater_reliability.qmd) as side-sections, but all of it answers one underlying question, so it has been consolidated here.

# Wald-Wolfowitz runs test on the sign of a series (p-value only; zeros
# dropped). Shared by the two autocorrelation tests below (§2 and §7).
runs_p <- function(x) {
  s <- sign(x[x != 0])
  n <- length(s)
  n1 <- sum(s > 0)
  n2 <- sum(s < 0)
  if (n1 == 0 || n2 == 0 || n < 3) {
    return(NA_real_)
  }
  runs <- 1 + sum(s[-1] != s[-n])
  mu <- 1 + 2 * n1 * n2 / n
  v <- 2 * n1 * n2 * (2 * n1 * n2 - n) / (n^2 * (n - 1))
  2 * pnorm(-abs((runs - mu) / sqrt(v)))
}

4. Image-level structure of disagreement (confound-free)

Code 
# 4
# The temporal tests show disagreement is organised at the image level, but
# the raw-score autocorrelation conflates several things (the experimental
# layout, the abundance of agreed 0s, per-image bias). A cleaner test, free of
# temporal order and of the self-vs-median issue, looks at the difference
# between two raters on the same CDA: the true severity cancels, leaving only
# their relative disagreement. If that difference is consistent within an
# image but shifts between images, disagreement has an image-level component.
# This is the intraclass correlation (ICC) of the pairwise difference with
# image as the grouping factor: the fraction of disagreement variance
# attributable to which image a CDA is on.
# All within-CDA rater pairs, oriented lower-ID minus higher-ID, with image label.
mk_pair <- function(d, a, b) {
  d %>%
    transmute(Basename, Median_Score,
      sa = .data[[paste0("Scorer", a)]], sb = .data[[paste0("Scorer", b)]],
      ya = .data[[paste0("Score", a)]], yb = .data[[paste0("Score", b)]]
    ) %>%
    filter(!is.na(sa), !is.na(sb), !is.na(ya), !is.na(yb)) %>%
    mutate(
      pair = paste(pmin(sa, sb), pmax(sa, sb), sep = "-"),
      diff = if_else(sa < sb, ya - yb, yb - ya)
    )
}
pairs <- bind_rows(mk_pair(canon, 1, 2), mk_pair(canon, 1, 3), mk_pair(canon, 2, 3)) %>%
  select(pair, Basename, Median_Score, diff)

# Random-effects (one-way ANOVA) ICC of the difference by image, for one rater-pair.
icc_by_pair <- function(df) {
  g <- df %>%
    group_by(Basename) %>%
    summarise(ni = n(), mi = mean(diff), .groups = "drop") %>%
    filter(ni >= 2)
  df <- df %>% semi_join(g, by = "Basename")
  k <- nrow(g)
  N <- nrow(df)
  if (k < 3 || N < 10) {
    return(tibble(k = k, N = N, icc = NA_real_, btw_sd = NA, wth_sd = NA))
  }
  grand <- mean(df$diff)
  ss_b <- sum(g$ni * (g$mi - grand)^2)
  g_mi <- g %>% select(Basename, mi)
  ss_w <- df %>%
    left_join(g_mi, by = "Basename") %>%
    summarise(s = sum((diff - mi)^2)) %>%
    pull(s)
  ms_b <- ss_b / (k - 1)
  ms_w <- ss_w / (N - k)
  n0 <- (N - sum(g$ni^2) / N) / (k - 1)
  var_b <- max(0, (ms_b - ms_w) / n0)
  var_w <- ms_w
  tibble(k = k, N = N, icc = var_b / (var_b + var_w), btw_sd = sqrt(var_b), wth_sd = sqrt(var_w))
}

run_icc <- function(dat, label) {
  res <- dat %>%
    group_by(pair) %>%
    group_modify(~ icc_by_pair(.x)) %>%
    ungroup() %>%
    filter(!is.na(icc)) %>%
    mutate(subset = label)
  cat(sprintf(
    "[%s] %d pairs | median ICC = %.3f | within-image SD = %.2f | between-image SD = %.2f\n",
    label, nrow(res), median(res$icc), median(res$wth_sd), median(res$btw_sd)
  ))
  res
}

7. Rescore drift autocorrelation (randomised order)

Code 
# 7.1
# The rescore originals were presented in a randomised order, so consecutive
# trials are unrelated images. Any autocorrelation in the drift (new - old)
# is therefore a pure sequential effect. The cost is power: only ~100 trials
# per rater.
rescore_files <- list.files(
  here("analyses", "06_intra_rater_reliability", "rescore_anon"),
  pattern = "[.]csv$", full.names = TRUE
)
# Rows are kept in file order = presentation order.
rescore <- bind_rows(lapply(rescore_files, function(f) {
  read_csv(f, show_col_types = FALSE) %>%
    mutate(
      Scorer = factor(scorer), seq = row_number(),
      old_score = as.integer(old_score), new_score = as.integer(new_score),
      drift = new_score - old_score
    )
})) %>%
  filter(!is.na(drift)) %>%
  group_by(Scorer) %>%
  mutate(cum = cumsum(drift - mean(drift))) %>%
  ungroup()

rescore_stats <- rescore %>%
  group_by(Scorer) %>%
  summarise(
    n = n(),
    lag1_acf = cor(head(drift, -1), tail(drift, -1)),
    runs_p = runs_p(drift),
    mean_drift = mean(drift), .groups = "drop"
  )

8. Relative anchoring test (not yet implemented)

The hypothesis: raters may score a CDA relative to the immediately-preceding CDA’s score (comparative anchoring), rather than the apparent image-blocking in §3/§5 being purely about shared visual content (lighting, leaf, background).

None of §2–§7 cleanly separate this from image-blocking, since almost all consecutive CDAs sharing an image (§3) also share a preceding score. A dedicated test would need to isolate the effect of the previous score from the effect of the previous image, e.g. by comparing residual autocorrelation for same-image pairs against a null model that only knows the image, not the specific preceding CDA.
