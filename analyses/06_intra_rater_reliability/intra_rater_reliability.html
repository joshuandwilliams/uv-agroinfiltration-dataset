Intra-Rater Reliability

Date: 2026-06-05

GOHREP

Goal:

Quantify how consistently each rater scores the same CDA on two separate occasions (intra-rater reliability). Assess whether rescoring changes agreement with the original ground truth (median score). Investigate how rescoring disagreements would change ground truth labels (median score).

Hypothesis:

  1. Raters will be more consistent with themselves on extreme scores (1, 6) and less consistent on intermediate scores (2–5).
  2. Rescoring will not systematically improve or worsen agreement with the median — any changes will reflect genuine scoring uncertainty rather than learning.

Rationale:

Only non-zero median CDAs were included in the rescoring set, since 0s are almost always agreed upon. Each rater was presented the same CDAs they originally scored, in a randomised order, without access to their original scores.

# This section compares two kinds of disagreement on the same set of
# non-zero-median CDAs:
#   1. Within-rater: for each rescored CDA, the difference between the new
#      and old score.
#   2. Between-rater: for each CDA, the difference between each pair of
#      original raters (Scorer1 - Scorer2, Scorer1 - Scorer3, Scorer2 -
#      Scorer3) - pairwise rater-vs-rater comparison, not a comparison to
#      the median.

7.3 Reliability coefficient: intra- vs inter-rater Krippendorff’s α

Code 
# 7.3.1
# Ordinal Krippendorff's alpha - the same statistic used for the full
# inter-rater panel in 05_inter_rater_agreement.qmd - applied here to each
# rater's two occasions (treating old_score and new_score as two raters).
# Using one coefficient for both keeps intra- and inter-rater reliability on
# a single comparable scale, and the ordinal metric respects that a 1<->6
# disagreement is worse than 1<->2 (the reason alpha was chosen over %
# agreement). It also handles missing values natively. Per-rater 95% CIs are
# bootstrapped over CDAs.
#
# `inter_alpha` below is NOT reused from 05_inter_rater_agreement.qmd - it is
# recomputed independently, from the original combined_cda_data_median.csv
# panel, restricted to non-zero-median CDAs only (to match what was
# available for rescoring; only non-zero-median CDAs were rescored - see
# GOHREP). That restriction is why it legitimately differs from 05's
# headline ordinal alpha, which is computed over all CDAs (0.805 here vs.
# 0.935 there - the abundant, near-unanimous median-0 CDAs inflate 05's
# figure). It is unrelated to the rescore data itself, which is far too
# small (~100 trials/rater, almost no shared images across raters) to
# support an inter-rater alpha of its own.
set.seed(42)

# Per-rater intra-rater alpha (old vs new as two raters) with bootstrap CIs.
intra_alpha <- rescore_data %>%
  filter(!is.na(old_score), !is.na(new_score)) %>%
  group_by(Scorer) %>%
  group_modify(~ {
    m <- rbind(.x$old_score, .x$new_score)
    a <- kripp.alpha(m, method = "ordinal")$value
    boot <- bootstrap_kripp_alpha(
      m,
      method = "ordinal", replace = TRUE, seed = NULL, suppress_warnings = TRUE,
      cache_path = here(
        "analyses", "06_intra_rater_reliability", "bootstrap_cache",
        paste0("intra_alpha_scorer_", .y$Scorer, ".rds")
      )
    )
    tibble(
      alpha = a,
      lo = quantile(boot, 0.025, na.rm = TRUE),
      hi = quantile(boot, 0.975, na.rm = TRUE)
    )
  }) %>%
  ungroup()

# Panel inter-rater alpha on the same non-zero-median CDAs (reference).
