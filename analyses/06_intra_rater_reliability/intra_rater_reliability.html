Intra-Rater Reliability

Date: 2026-06-05

GOHREP

Goal:

Quantify how consistently each rater scores the same CDA on two separate occasions (intra-rater reliability). Assess whether rescoring changes agreement with the original ground truth (median score). Investigate how rescoring disagreements would change ground truth labels (median score).

Hypothesis:

  1. Raters will be more consistent with themselves on extreme scores (1, 6) and less consistent on intermediate scores (2–5).
  2. Rescoring will not systematically improve or worsen agreement with the median — any changes will reflect genuine scoring uncertainty rather than learning.

Rationale:

Only non-zero median CDAs were included in the rescoring set, since 0s are almost always agreed upon. Each rater was presented the same CDAs they originally scored, in a randomised order, without access to their original scores.

  filter(!is.na(old_score)) %>%

    s3         = ifelse(scorer_id == Scorer3, new_score, Score3),

  ungroup()

7. Within- vs between-rater variation

Code 
# 7
# This section compares two kinds of disagreement on the same set of
# non-zero-median CDAs:
#   1. Within-rater: for each rescored CDA, the difference between the new
#      and old score.
#   2. Between-rater: for each CDA, the difference between each pair of
#      original raters (Scorer1 - Scorer2, Scorer1 - Scorer3, Scorer2 -
#      Scorer3) - pairwise rater-vs-rater comparison, not a comparison to
#      the median.
# Both are restricted to non-zero-median CDAs. If the within- and
# between-rater spreads are similar, most label noise is irreducible scoring
# uncertainty rather than systematic between-rater bias.
between_raw <- read_csv(
  here(
    "analyses", "01_generate_raw_data", "04_representative_bounding_box_and_score",
    "combined_cda_data_medoid.csv"
  ),
  show_col_types = FALSE
) %>%
  select(Basename, Row, Col, Pos, Score1, Score2, Score3, Median_Score) %>%
  mutate(across(c(Score1, Score2, Score3, Median_Score), as.numeric)) %>%
  filter(Median_Score > 0)

# Within-rater differences (one per rescored CDA) and between-rater pairwise differences.
within_diff <- rescore_data %>%

between_diff <- between_raw %>%

# 7.3.1
# Interval Krippendorff's alpha - the same metric now used for the full
# inter-rater panel in 05_inter_rater_agreement.qmd (05 was switched from
# ordinal to interval; see its section 7.1 for the rationale) - applied here
# to each rater's two occasions (treating old_score and new_score as two
# raters). Using one metric for both keeps intra- and inter-rater reliability
# on a single comparable scale; the interval metric applies a fixed,
# interpretable spacing between severity scores rather than one derived from
# this sample's score frequencies. It also handles missing values natively.
# Per-rater 95% CIs are bootstrapped over CDAs with replacement (n-of-n) - the
# standard nonparametric bootstrap. Each rater rescored only ~100 CDAs, so a
# fixed-size subsample without replacement (as 05's headline figure uses) is
# not possible here, and a with-replacement bootstrap is in any case the
# correct sampling distribution for a CI on the estimate.
#
# `inter_alpha` below is NOT reused from 05_inter_rater_agreement.qmd - it is
# recomputed independently, from the original combined_cda_data_medoid.csv
# panel, restricted to non-zero-median CDAs only (to match what was available

# restriction is why it legitimately differs from 05's headline alpha, which is
# computed over all CDAs (the abundant, near-unanimous median-0 CDAs inflate
# 05's figure). It is given its own with-replacement bootstrap CI so that intra-

8. Gwet’s AC2: a prevalence-robust cross-check

Krippendorff’s interval α (computed on the inter-rater panel in 05_inter_rater_agreement.qmd, sections 7.1–7.2) estimates chance agreement from the observed score distribution, so it can be depressed when one class dominates (the kappa “high-agreement paradox”). Gwet’s AC2 uses a chance-agreement model that is stable under class imbalance. AC2 with quadratic weights is the direct analogue of interval α — same inter-rater panel, same 1,000-draw / 500-CDA subsample scheme — computed here for the full dataset and the non-zero-median subset so it can be read alongside the α values. Where AC2 and α agree, the α value is not a paradox artefact; where they diverge, the gap is the prevalence effect.

# 8.1.3
# The two coefficients' bootstrap distributions are drawn as two SEPARATE plots
# (translucent overlay, not stacked), one per CDA set, and saved as individual
# PNGs so they can be stacked in the thesis figure. Each dashed line marks a
# distribution's mean, labelled with its value (each label offset left or right of
# its line to avoid collisions - see make_panel). A dotted mark at X = 0.80 is
# shown on both, and both panels share common x-limits so they read on a single
# scale when stacked. The colour legend is drawn once, above the all-CDAs (top)
# plot, and reads for both panels. The panel (data) area is pinned to an identical
# absolute size in both files (via the gtable in save_fixed_panel) so the two
# align exactly when stacked in the thesis figure.
coef_pal <- c("Krippendorff's α" = "#4477AA", "Gwet's AC2" = "#CC6677")

make_panel <- function(boot_alpha, boot_ac2, xlab, show_legend,
                        alpha_side, ac2_side, x80_side) {
  # Each value label is placed just left ("left") or just right ("right") of its
  # own vertical line; the side is chosen per panel so no two labels collide - in
  # the all-CDAs panel alpha and AC2 are close, so alpha goes left and AC2 right;
  # in the non-zero panel alpha is close to the 0.80 mark, so the mark goes left
  # and alpha goes right. All three labels share one height and font size.
  hj <- function(side) if (side == "left") 1.1 else -0.1

  df <- bind_rows(
    tibble(stat = boot_alpha, Coefficient = "Krippendorff's α"),
    tibble(stat = boot_ac2, Coefficient = "Gwet's AC2")
  ) %>%
    mutate(Coefficient = factor(Coefficient, levels = c("Krippendorff's α", "Gwet's AC2")))

  means <- df %>%
    group_by(Coefficient) %>%
    summarise(m = mean(stat), .groups = "drop")
  m_alpha <- means$m[means$Coefficient == "Krippendorff's α"]
  m_ac2 <- means$m[means$Coefficient == "Gwet's AC2"]

  ggplot(df, aes(x = stat, fill = Coefficient)) +
    geom_histogram(position = "identity", alpha = 0.5, binwidth = 0.005, colour = NA) +
    geom_vline(
      data = means, aes(xintercept = m, colour = Coefficient),
      linetype = "dashed", linewidth = 0.8, show.legend = FALSE
    ) +
    geom_vline(xintercept = 0.8, linetype = "dotted", colour = "black", linewidth = 0.6) +
    annotate("text",
      x = m_alpha, y = Inf, label = sprintf("%.3f", m_alpha),
      colour = coef_pal[["Krippendorff's α"]], hjust = hj(alpha_side), vjust = 1.5, size = 3.3
    ) +
    annotate("text",
      x = m_ac2, y = Inf, label = sprintf("%.3f", m_ac2),
      colour = coef_pal[["Gwet's AC2"]], hjust = hj(ac2_side), vjust = 1.5, size = 3.3
    ) +
    annotate("text",
      x = 0.8, y = Inf, label = "X = 0.80",
      colour = "grey30", hjust = hj(x80_side), vjust = 1.5, size = 3.3
    ) +
    scale_fill_manual(values = coef_pal, name = NULL) +
    scale_colour_manual(values = coef_pal, guide = "none") +
    coord_cartesian(xlim = c(0.75, 0.965)) +
    scale_y_continuous(expand = expansion(mult = c(0, 0.22))) +
    labs(x = xlab, y = "Count") +
    theme_minimal() +
    theme(
      axis.text = element_text(size = 12),
      axis.title = element_text(size = 13),
      legend.position = if (show_legend) "top" else "none",
      legend.text = element_text(size = 12)
    )
}

# Pin the panel (data area) to an identical absolute size in both files, so the
# two subplots line up exactly when stacked in the thesis figure, then save.
save_fixed_panel <- function(p, filename, canvas_h) {
  g <- ggplotGrob(p)
  is_panel <- g$layout$name == "panel"
  g$widths[unique(g$layout$l[is_panel])] <- grid::unit(18, "cm")
  g$heights[unique(g$layout$t[is_panel])] <- grid::unit(6, "cm")
  ggplot2::ggsave(
    here("analyses", "06_intra_rater_reliability", "thesis_plots", filename),
    plot = g, width = 8.6, height = canvas_h, units = "in", dpi = 300
  )
  invisible(g)
}
