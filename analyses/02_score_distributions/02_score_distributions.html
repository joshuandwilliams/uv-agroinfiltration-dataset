Date: 8/5/26

# 2.1
# Scoring key (scores 0-6, left to right). The original key is a CMYK JPEG, so an
# sRGB copy (converted via its ICC profile) is read here to keep colours faithful.
# The number strip is cropped off (rows 189-554 keep just the 7 panels). The example
# columns carry the score labels and are boxed to the same width as the key panels.
key <- readPNG(here("analyses", "02_score_distributions", "assets", "lesion_score_key_rgb.png"))
key_raster <- as.raster(key[189:554, , 1:3])
W <- dim(key)[2] # key width (px)
key_h <- length(189:554) # cropped key height (panels only)

# key panel edges (measured) -> example column boxes match these exactly
L <- c(7, 404, 801, 1195, 1586, 1978, 2369)
R <- c(389, 786, 1180, 1571, 1963, 2354, 2745)
cen <- (L + R) / 2

# Four random example CDAs per score (0-6)
set.seed(42)
n_per <- 4
thumbs <- lapply(0:6, function(sc) {
  files <- list.files(here("data", "cropped_images", sc), full.names = TRUE, pattern = "\\.tif$")
  lapply(sample(files, n_per), function(f) as.raster(readTIFF(f)))
})

# Layout in pixel units (bottom to top): key panels, "Scoring Key" title, grid of boxed examples, score labels.
# Boxes are centred on the key panels but a little narrower, leaving clear gaps between columns.
box_hw <- 160
pad <- 16
tgap <- 12
side <- 2 * box_hw - 2 * pad
title_band <- 150
lab_band <- 150
box_h <- n_per * side + (n_per - 1) * tgap + 2 * pad
g0 <- key_h + title_band # grid (box) bottom
g1 <- g0 + box_h # grid (box) top
Htot <- g1 + lab_band

boxes <- data.frame(xmin = cen - box_hw, xmax = cen + box_hw, ymin = g0, ymax = g1)

thumb_layers <- list()
for (j in 1:7) {
  for (i in seq_len(n_per)) {
    ytop <- g1 - pad - (i - 1) * (side + tgap)
    thumb_layers <- c(
      thumb_layers,
      annotation_raster(thumbs[[j]][[i]],
        xmin = cen[j] - side / 2, xmax = cen[j] + side / 2,
        ymin = ytop - side, ymax = ytop, interpolate = TRUE
      )
    )
  }
}

p <- ggplot() +
  annotation_raster(key_raster, xmin = 0, xmax = W, ymin = 0, ymax = key_h, interpolate = TRUE) +
  annotate("text", x = W / 2, y = key_h + title_band / 2, label = "Scoring Key", size = 7) +
  thumb_layers +
  geom_rect(
    data = boxes, aes(xmin = xmin, xmax = xmax, ymin = ymin, ymax = ymax),
    fill = NA, colour = "black", linewidth = 0.7
  ) +
  annotate("text", x = cen, y = g1 + lab_band / 2, label = 0:6, size = 8) +
  coord_fixed(xlim = c(0, W), ylim = c(0, Htot), expand = FALSE) +
  theme_void()

ggsave(here("analyses", "02_score_distributions", "thesis_plots", "cdaexamples.png"),
  p,
  width = W / 300, height = Htot / 300, dpi = 300, device = ragg::agg_png, bg = "white"
)

# Largest-remainder rounding so displayed percentages sum to exactly 100.0
pct_sum_100 <- function(counts, digits = 1) {
  scaled <- counts / sum(counts) * 100 * 10^digits
  floor_vals <- floor(scaled)
  deficit <- round(100 * 10^digits) - sum(floor_vals)
  top_up <- order(-(scaled - floor_vals))[seq_len(deficit)]
  floor_vals[top_up] <- floor_vals[top_up] + 1
  floor_vals / 10^digits
}

all_counts <- all_counts %>% mutate(Pct = pct_sum_100(Count))
median_counts <- median_counts %>% mutate(Pct = pct_sum_100(Count))

6. Discussion

6.1 Score distributions

  • The score distributions collected reflect experimental design and biological outcomes. Some experiments have quite binary outcomes (0 or 6) whilst others have more balanced phenotypes, showing a range of intermediate scores.
  • A score of 0 is common because of both experimental (intentional negative control included in all experiments) and biological (no expression or no immune response) outcomes.

6.2 Differences between raters

  • The differences in the score distributions collected by each rater could be down to the images they were randomly allocated, but it could also reflect differences in scoring strategy or interpretation of the scoring key.
  • The distribution of scores may be due to the random allocation of images during the collection process. The images came from a series of different projects in the Banfield lab, which worked with different biological systems that may show different phenotypic distributions.
  • The difference in overall score count are due to three raters (1, 5, and 7) only scoring one of the two datasets.

6.3 Scoring disagreement

  • Scoring disagreement may arise due to individual (scoring biases driven by past scoring experiences) or experimental (ambiguous scoring key interpreted differently by different raters) reasons.
  • Score 0 is more unambiguous than intermediate scores. It is a complete lack of cell death area. This may be why cell death areas with a median score of 0 saw fewer disagreeing scores.
  • Cell death areas with median 0 scores receive far less scoring variance, and almost nothing beyond the adjacent score. It is an unambiguous task.
  • Intermediate scores, which may be more subjective or less clearly align to the scoring key, are scored less consistently.

6.4 Missing scores

  • Missed scores represent intentional choices, not accidental omissions.
  • The annotation tool includes a skip button which the annotators were instructed use for cell death areas that were highly unclear (e.g. leaf folding), damaged, or overlapping with adjacent cell death areas. Different interpretations of these descriptions may account for the variable skip counts.
  • Score 0 was the most common score collected, so it being the most commonly missed makes sense. Damaged leaves (often caused by the agroinfiltration syringe puncturing the leaf) also often appeared as score 0.
