Sequential and image-level structure of scoring disagreement

Date: 2026-06-15

GOHREP

Goal:

Determine whether raters’ over- and under-scoring errors are independent per CDA, or whether they cluster — either in time (a sequential momentum / anchoring effect, where having just scored high makes the next score more likely to be high) or by image (an experiment-level effect, where a rater’s deviation is consistent within a leaf/image but shifts between images).

Hypothesis:

  1. In the rescore task (originals presented in randomised order), drift new − old will show little sequential autocorrelation — there is no stimulus structure to anchor to.
  2. In the original scoring (CDAs scored in image order), residual disagreement will appear autocorrelated, but this will be an image-blocking effect (consecutive CDAs share a leaf) rather than genuine temporal momentum.
  3. Between-rater disagreement will carry a modest but real image-level component: two raters’ relative offset is more consistent within an image than between images.

Rationale:

This follows up a question raised in 06_intra_rater_reliability: do over-/under-scoring patterns occur in groups? The danger is mistaking experimental structure for rater psychology. Original scoring is not random — infiltration layouts place controls (0s) together, leaves differ in lighting/background, and neighbouring spots on a leaf share treatment — so consecutive scores are correlated for reasons that have nothing to do with sequential anchoring. We therefore (a) use the randomised-order rescore as a clean temporal test, (b) decompose the original-scoring autocorrelation into within- vs across-image, and (c) test image-level structure directly with a confound-free pairwise comparison.

# Wald-Wolfowitz runs test on the sign of a series (p-value only; zeros dropped).
runs_p <- function(x) {
  s <- sign(x[x != 0])
  n <- length(s)
  n1 <- sum(s > 0)
  n2 <- sum(s < 0)
  if (n1 == 0 || n2 == 0 || n < 3) {
    return(NA_real_)
  }
  runs <- 1 + sum(s[-1] != s[-n])
  mu <- 1 + 2 * n1 * n2 / n
  v <- 2 * n1 * n2 * (2 * n1 * n2 - n) / (n^2 * (n - 1))
  2 * pnorm(-abs((runs - mu) / sqrt(v)))
}

2. Temporal test 1 — rescore drift (randomised order)

The rescore originals were presented in a randomised order, so consecutive trials are unrelated images. Any autocorrelation in the drift new − old is therefore a pure sequential effect. The cost is power: only ~100 trials per rater.

3. Temporal test 2 — original scoring (image-ordered)

The original scoring was done in image order, with thousands of scores per rater — far more power, but consecutive CDAs usually share an image. Each score is compared to the leave-one-out consensus (the median, i.e. mean, of the other two raters on that CDA), giving a residual score − consensus. Scores are matched to the canonical panel by image and CDA position; the leave-one-out reference removes the self-inclusion that would otherwise force a score to match its own median.

3.1 Within-image vs across-image autocorrelation

If the autocorrelation is genuine temporal momentum it should persist when consecutive scores come from different images; if it is image-blocking it should vanish at image boundaries.

4. Image-level structure of disagreement (confound-free)

The temporal tests show disagreement is organised at the image level, but the raw-score autocorrelation conflates several things (the experimental layout, the abundance of agreed 0s, per-image bias). A cleaner test, free of temporal order and of the self-vs-median issue, looks at the difference between two raters on the same CDA: the true severity cancels, leaving only their relative disagreement. If that difference is consistent within an image but shifts between images, disagreement has an image-level component. This is the intraclass correlation (ICC) of the pairwise difference with image as the grouping factor: the fraction of disagreement variance attributable to which image a CDA is on.

Code 
# 4
# All within-CDA rater pairs, oriented lower-ID minus higher-ID, with image label.
mk_pair <- function(d, a, b) {
  d %>%
    transmute(Basename, Median_Score,
      sa = .data[[paste0("Scorer", a)]], sb = .data[[paste0("Scorer", b)]],
      ya = .data[[paste0("Score", a)]], yb = .data[[paste0("Score", b)]]
    ) %>%
    filter(!is.na(sa), !is.na(sb), !is.na(ya), !is.na(yb)) %>%
    mutate(
      pair = paste(pmin(sa, sb), pmax(sa, sb), sep = "-"),
      diff = if_else(sa < sb, ya - yb, yb - ya)
    )
}
pairs <- bind_rows(mk_pair(canon, 1, 2), mk_pair(canon, 1, 3), mk_pair(canon, 2, 3)) %>%
  select(pair, Basename, Median_Score, diff)

# Random-effects (one-way ANOVA) ICC of the difference by image, for one rater-pair.
icc_by_pair <- function(df) {
  g <- df %>%
    group_by(Basename) %>%
    summarise(ni = n(), mi = mean(diff), .groups = "drop") %>%
    filter(ni >= 2)
  df <- df %>% semi_join(g, by = "Basename")
  k <- nrow(g)
  N <- nrow(df)
  if (k < 3 || N < 10) {
    return(tibble(k = k, N = N, icc = NA_real_, btw_sd = NA, wth_sd = NA))
  }
  grand <- mean(df$diff)
  ss_b <- sum(g$ni * (g$mi - grand)^2)
  g_mi <- g %>% select(Basename, mi)
  ss_w <- df %>%
    left_join(g_mi, by = "Basename") %>%
    summarise(s = sum((diff - mi)^2)) %>%
    pull(s)
  ms_b <- ss_b / (k - 1)
  ms_w <- ss_w / (N - k)
  n0 <- (N - sum(g$ni^2) / N) / (k - 1)
  var_b <- max(0, (ms_b - ms_w) / n0)
  var_w <- ms_w
  tibble(k = k, N = N, icc = var_b / (var_b + var_w), btw_sd = sqrt(var_b), wth_sd = sqrt(var_w))
}

run_icc <- function(dat, label) {
  res <- dat %>%
    group_by(pair) %>%
    group_modify(~ icc_by_pair(.x)) %>%
    ungroup() %>%
    filter(!is.na(icc)) %>%
    mutate(subset = label)
  cat(sprintf(
    "[%s] %d pairs | median ICC = %.3f | within-image SD = %.2f | between-image SD = %.2f\n",
    label, nrow(res), median(res$icc), median(res$wth_sd), median(res$btw_sd)
  ))
  res
}

5.5 Overall narrative — confounds and interpretation

Same image = same experiment. Original scoring is not a random sequence. CDAs on one image are spots on one leaf from one infiltration, so they share construct, leaf age, lighting and background. Two effects follow: (i) the underlying severities are correlated, and (ii) a rater’s reading of that leaf (exposure, contrast, what counts as “necrotic” under that lighting) is correlated. The §3 within-image autocorrelation and the §4 ICC both capture this image-level structure; neither is evidence of temporal anchoring, which the randomised rescore (§2) and the across-image boundary (§3.1) both rule out.

The abundance of 0s and non-random layout. Infiltration layouts group controls together, so a rater genuinely does see runs of 0s — but those are near-universally agreed, so they contribute agreement, not disagreement structure. This is why the analyses use residuals / pairwise differences rather than raw scores (which would be trivially autocorrelated by the design), and why the §4 ICC is computed both with and without 0s. The result is reassuring: excluding 0s increases the image-level ICC, so the structure lives in the contested mid-range CDAs, not in the clustered controls.

Is class balancing necessary? For the temporal tests, no — and it would be harmful: down-sampling or re-weighting score classes destroys the true adjacency of the sequence, so a “lag-1” on a balanced series no longer means consecutive-in-time. The appropriate controls there are analysing residuals (not raw scores) and the within/across-image split, both of which are done. For the image-level ICC, balance is handled implicitly: the difference between two raters already removes the severity (class) signal, and reporting the non-zero subset alongside the full set shows the conclusion is not driven by the dominant 0 class.

Overall. Over-/under-scoring does not have temporal momentum across contexts — a rater’s last score does not pull their next one once the image changes. What is real is a modest image-level structure to disagreement: two raters’ relative calibration drifts somewhat from image to image (plausibly per-leaf lighting/background and per-session adaptation) while staying more consistent within an image. Most disagreement, however, remains CDA-specific — the irreducible ambiguity of scoring an individual cell-death area.
